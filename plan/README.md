# 原生后端实施路径

唯一交付物是 Tauri 2 + `REF/frontend/app` 的桌面安装包。
本文只定义目标拆分与验收，不记录当前进度；项目现状只通过 git commit description 记录。

| 切片 | 必须实现的原生能力 | 验收重点 |
|---|---|---|
| B1：状态与事件 | 任务、笔记、资料、项目、偏好、草稿、备份、启动恢复、事件 outbox | 命令读写、跨页同步、SQLite 重启恢复、Last-Event-ID 续接 |
| B2：生成与学习 | 材料解析、八步生成、讲义、知识地图、练习、复习、报告 | 真实模型与材料、实时输出、取消续接、局部重跑、原生判分 |
| B3：Agent 与模型 | Agent 工具循环、模型档案与检测、任务路由、故障转移、同步 | 实际协议请求、系统密钥库、事件落盘、异常与取消计量 |
| B4：其余产品功能 | 社区、安全、插件、分享、导出、运维 | 真实副作用、权限与限制、导出内容、失败回滚 |
| B5：冗余清理 | 删除已被替代的 Python/Reasonix 后端与重复资产 | 没有无人使用的产品路径，安装包与保留测试通过 |

功能范围及交互验收以 [`note/14-Tauri原生后端覆盖清单.md`](../note/14-Tauri原生后端覆盖清单.md)
为准。每个切片必须形成真实实现并删除对应模拟分支；不得以计划、静态页面或
模拟成功代替完成证据。
