## 一、目标仓库布局

```
Deep-tutor/
├── go.mod                  # module deep-tutor（Go 1.25+，toolchain 固定）
├── go.sum
├── Makefile                # make build / lint / check / studio / cross（沿用 REF 并品牌化）
├── .golangci.yml / .golangci-version / .goreleaser.yaml
├── DEEPTUTOR.md            # 工程规约（自 REF/REASONIX.md 改造，见 §五）
├── AGENTS.md               # agent 工作指引（根，指向 note/12 与本方案）
├── internal/               # 内核（自 REF 拷贝+裁剪+重命名，见 §二/§三）
│   ├── assembly/ base/ contract/ ext/ frontend/ model/
│   ├── platform/ runtime/ safety/ session/ state/ tools/
│   └── web/                # 【新增】Deep-tutor 多用户服务层（04）：认证/配额/装配/API/shim
├── cmd/
│   ├── deep-tutor/         # 主二进制（serve/CLI/TUI/ACP 子命令）
│   └── studio-host/        # Studio 宿主（自 reasonix-studio-host）
├── desktop/                # Electron Studio（嵌套 module，自 REF desktop/）
├── tools/                  # repolint 等（门禁，#41）
├── sdk/                    # Go 扩展 SDK（插件 sidecar 开发用）
├── docs/
│   ├── kernel/             # 内核文档（自 REF docs/ 拷贝，保留 SPEC/TOOL_CONTRACT 等）
│   └── archive/            # Python 时代归档（chat/err/plan-v1，已入 git）
├── frontend/               # 旧 SPA（阶段①② shim 回归工具，阶段④删 #47）
├── backend/                # Python 后端（保留至阶段① M5 验收后停用，阶段④删）
├── plugins/ plugin-examples/ extension/ skills/ scripts/
├── plan/                   # 本方案（plan/reasonix/）+ 归档指引
├── note/                   # 分析与决策档案（已入 git）
├── API.md                  # v1 契约 = shim 兼容基准（状态头已加）
├── README.md / stage.md / err.md(归档) …
└── data/                   # 运行时数据（gitignore；02 §五总图）
```

要点：
- **模块名 `deep-tutor`**：import 全量重写 `reasonix/…` → `deep-tutor/…`（§三流程）。
- **internal/web/ 是唯一的"Deep-tutor 服务层"**：多用户、认证、配额、per-user 装配、新 /api 与 shim 全部收在这一层，**内核包不做多用户感知**（分层原则见 00 §三；详细设计在 04）。这是"最小改内核"与"自由修改"的平衡点：多用户是装配问题不是内核问题。
- 阶段① M1 期间 backend/ 原样保留可运行（R9：M5 验收时点才停旧后端、切 41173）。

## 三、拷贝与重命名流程（M1 执行细则）

1. **裸拷贝**：按 §二清单拷入目标位置（一次 commit：`chore(kernel): 引入 Reasonix studio 基线（裁剪后）`，附来源快照说明与 MIT 声明）。
2. **模块与 import 重命名**（独立 commit，只做机械重写）：
   - `go.mod`: `module deep-tutor`；desktop 嵌套 module 的 `replace reasonix => ../` 同步改。
   - 全树 `reasonix/internal/` → `deep-tutor/internal/`、`reasonix/desktop/` → `deep-tutor/desktop/`（用脚本统一替换 import path，不用 gofmt -r——包路径字符串也出现在文档/测试金样里，需 grep 复核 `reasonix` 残留）。
   - 二进制名：cmd/reasonix → cmd/deep-tutor；`reasonix.example.toml` → `deeptutor.example.toml`（仅作文档示例；**运行时配置权威是 DB+data/，不是 toml**，见 04 §三）。
   - 验收：`go build ./... && go vet ./... && go test ./internal/...` 全绿才提交。
3. **品牌化**（独立 commit）：README/关于页/桌面端标题/图标位 → Deep-tutor、Deep-tutor Studio；**保留**所有上游版权头与 LICENSE（MIT）文件；新增 NOTICE 段（§四）。
4. **裁剪补刀**：对 §二"剔除"表中拷入后又发现引用的地方清引用（`go build` 驱动）。
