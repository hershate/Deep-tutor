# 知舟设计系统

## 设计原则

界面服务于学习任务完成、状态检查和键盘操作。窄窗口保留全部功能，通过单栏、抽屉和局部滚动调整布局，不删除内容。

## 色彩与主题

- Primitive：`--pine-950 / 700 / 600`、`--lime-400 / 300`、`--paper-50 / 100`、`--ink-950 / 700 / 500`。
- Semantic：`--bg`、`--surface`、`--text`、`--muted`、`--border`、`--accent`、`--accent-bright` 及状态色。
- 按钮、导航、徽记、进度和学习工作区只消费语义令牌。
- 浅色主题使用冷调纸绿背景；深色主题使用同色相的低明度表面。正文对比度不低于 4.5:1。
- 品牌色用于侧栏、当前位置、主要行动和学习进度，不使用渐变文字。

## 字体与排版

字体栈为 `Aptos, Noto Sans SC, Source Han Sans SC, PingFang SC, Microsoft YaHei, sans-serif`。中文不使用斜体。正文默认 16px，辅助文字不小于 12px；窄窗解析状态紧凑徽章使用 10px，并以省略截断保持布局。阅读正文行高 1.85，操作区行高 1.5–1.75。标题通过字重、尺寸和间距区分层级。大字模式通过 `body` 的 `zoom: 1.12` 等比放大固定字号。

## 布局与响应式

- 桌面布局由 248px 侧栏、64px 顶部工具栏和流体工作区组成。
- 学习空间由目录、阅读和导师三栏组成；宽度不足时依次堆叠，1280px 起显示完整三栏。
- 页面默认使用单栏，700px 起扩展，1024px 起显示持久侧栏。
- 组件另使用 640、1080、1100、1180、1240 和 1320px 断点；具体规则以 `src/styles.css` 为准。
- 间距以 4px 为基，常用值为 4/6/8/10/12/16/20px，不要求全部取 4/8 倍数。
- 表面圆角为 8–18px；边框与分隔线优先于阴影。

## 组件与交互

- 每屏的主要按钮只设置一个视觉焦点，次级按钮使用表面色与边框。
- 任务、练习、复习、笔记、项目、图谱和报告按数据结构选择列表、表格、图谱或卡片，不统一套用卡片网格。
- 统一 `Modal` 支持关闭按钮、Esc、背板点击和焦点圈禁；Esc 由弹层栈仲裁，一次只关闭最上层。可见焦点使用主题变量，亮色与暗色焦点圈对比度分别为 6.5:1 和 13.79:1，满足 Focus Appearance 3:1。
- 主要行动与触屏路径上的控件不小于 44px。桌面指针环境中的紧凑次级控件可从 26px 起，必须保留可见焦点和键盘操作。隐藏功能同时支持点击，不依赖悬停。
- 动态文本使用 `overflow-wrap:anywhere`，flex/grid 文本列设置 `min-width:0`；表格、图谱、公式和代码只在各自容器内滚动。

## 学习流程

- 首页同时呈现学习任务清单和近 7 天学习记录；掌握度必须关联练习、复习或项目证据。
- 复习翻卡使用过渡动画；启用减弱动态效果时关闭过渡。
- 方案生成使用四步向导，明确呈现可选资料、暂存、解析、运行、警告、取消和终态。无资料方案使用通用框架。
- Agent 支持通用问答与可选方案上下文，通过多会话、工具事件、产物审批和预算侧栏展示执行状态。
- Wiki 引用、备份预演和只读分享显示来源、覆盖范围和失效状态。
- 模型接入中心通过档案列表、分步编辑器、任务路由表和脱敏配置预览管理连接设置，区分端点检测与真实模型请求，并说明本地代理和密钥边界。

## 数据展示

学习记录、模型结果、量规和同步状态必须来自真实后端，不使用合成数据冒充。原生结果必须来自真实命令，引用展示具体资料位置；本地保存不表示已完成云同步。

## 验收要求

- 在 1440px 桌面和 375px 窄窗口检查全部应用页面及只读分享，页面不得横向溢出。
- 主导航、方案生成、Agent 工具审批、Wiki 引用、公式笔记、复习、主观题、打卡、备份、导出和模型供应商测试必须调用真实后端，不能只有界面反馈。
- 检查供应商添加、任务路由、故障转移、聚合模式、Deep Link、JSON 导入脱敏和配置导出。
- StudyRoom、Library、PlanGenerator、AgentCenter、Integrations 和 ProviderHub 六个页面按需加载；运行期间不得出现控制台错误。

构建成功和协议夹具不能替代真实环境验收。
