# Product

## Platform

Tauri 2 桌面应用，唯一交付形态为安装后运行的应用，不提供浏览器 SPA、Electron 或独立服务端。

## Stack

React + TypeScript + Vite + Tauri 2（Rust 壳与原生后端）。界面来源为用户提供的 `REF/frontend/app`。

## Users and purpose

面向以自学为主的学习者，围绕考试、技能或兴趣目标，连接目标、诊断、计划、资料、理解、练习、复习、项目与报告。成功意味着学习者知道下一步做什么，并能看见真实掌握证据。

产品不是课程列表或独立聊天框，而是带有上下文 AI 导师的个人学习工作台。

## Operating context

桌面多栏学习工作台，窄窗口使用单栏布局。业务状态、材料原件、任务执行和实时事件由应用原生后端管理，支持本地多用户独立工作区。

## Capabilities and constraints

- 方案与学习：四源输入、原生解析、目标澄清、八步生成、引用校验、确定性排期、局部重生成、讲义与知识地图。
- 练习与复习：节点针对练习、选择/填空/简答/论述、真实评分、错题变式、模拟考试、间隔复习与保持率。
- Agent 与模型：真实会话、工具循环、记忆和产物审批、网络检索、任务路由、故障转移、Token 计量和预算。
- 笔记与资料：自由笔记、文件选择器与窗口拖放导入、ZIP 导入导出、KB/Wiki 引用问答、真实知识关联、网页抓取、媒体原件预览。
- 项目与报告：真实里程碑、阶段成果、模型量规、迭代笔记、专注记录、学习趋势与建议。
- 社区与插件：本机讨论、互评、小组、预约和声明式事件插件，不虚构在线成员或执行任意脚本。
- 数据与安全：全量备份、只读分享、原生多格式导出（落盘后可在资源管理器中定位）、WebDAV/S3 同步、JWT/PAT、角色、配额和独立工作区；外部链接一律经系统浏览器打开。
- 运维：数据库健康检查、白名单清理、事件续接、取消恢复、异常计量与原子写入。

API Key 只能经一次性表单进入系统密钥库。供应商、网页、同步和导出必须返回真实结果或明确错误。

模型只处理文字。扫描件 OCR 和音视频内容识别不属于当前实现；媒体仅提供原件预览，不生成字幕或识别结果。语言偏好可持久化，默认界面为中文。

## Brand commitments

产品名：知舟 Deep Tutor。操作以学习闭环和真实证据为中心，视觉遵循用户提供的 Impeccable 设计方法。

## Evidence and trust

页面展示的学习记录、模型输出、量规、成本和同步状态必须来自真实后端。静态文案、编译结果或通知不能作为功能完成证明。真实供应商、媒体编码播放和交互安装需要单独验收。

## Product principles

1. 下一步行动优先于信息堆积。
2. 掌握度必须有练习、复习或项目证据。
3. AI 优先提示与反馈，而非替代学习者完成。
4. 关键操作可见、可撤销或可恢复。
5. 功能不得牺牲阅读、响应式与无障碍体验。

## Accessibility & Inclusion

支持键盘操作、可见焦点、减弱动态效果、字号与高对比度设置，并保证窄窗口基本可用性。
