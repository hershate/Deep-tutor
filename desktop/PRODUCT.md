# Product

<!-- impeccable:product-schema 1 -->

## Platform

Tauri 2 桌面应用（唯一用户界面，不再交付浏览器 SPA 或 Electron）。

## Stack

React + TypeScript + Vite + Tauri 2（Rust 壳），界面来源为用户提供的 `REF/frontend/app`。

## Users

以自学为主的学习者，需要围绕考试、技能或兴趣目标管理完整学习过程。

## Product Purpose

将目标、诊断、计划、资料、理解、练习、复习、项目和报告串成连续学习闭环。成功意味着学习者始终知道下一步做什么，并能看见掌握度证据。

## Positioning

不是课程列表或独立聊天框，而是带有上下文 AI 导师的个人学习操作系统。

## Operating Context

桌面多栏深度学习工作台，窄窗口使用单栏布局。学习操作和设置由应用原生后端持久化。

## Capabilities and Constraints

包含今日、AI 方案生成、学习计划、学习空间、知识地图、Agent 工作台、练习测评、间隔复习、自由笔记、KB 文档与 Wiki 引用问答、项目作品、总览／日历／按方案报告、学习社区、插件与模型供应商、备份、只读分享和访问安全设置。

方案生成覆盖四源输入、暂存解析、目标澄清、实时进度、断线续接、五维校验与局部重生成；导出覆盖 Markdown、系统打印 PDF、ICS、Anki 降级 TSV、HTML 幻灯片及插件格式。

独立模型接入中心提供 18 种官方／兼容／本地供应商预设、档案增删改、端点与模型请求检测、直连／本地路由／聚合三种模式、按学习任务分配模型、故障转移队列、Deep Link 与 JSON 脱敏导入导出、WebDAV／S3 同步流程。

API Key 经一次性表单进入系统密钥库，不进入 WebView 长期存储、日志、导出或同步载荷。

当前正分片接入 Tauri 原生后端：commands、events、SQLite 与后端异步任务提供真实结果。

- 材料暂存、去重、文本层解析、取消、恢复、删除与导出由原生实现。
- 模型档案、系统密钥库、OpenAI Chat 的模型列表、真实请求检测和可取消的流式输出已接入。
- 任务路由、模型覆盖和聚合模型选择已接入真实调用链，配置与真实路由日志保存在 SQLite；路由在进程内执行，不启动 HTTP 服务。
- 路由模式支持真实故障转移队列、单上游重试、超时、连续失败熔断、冷却与半开恢复，记录每次真实上游尝试；取消不重复生成或切换。
- OpenAI Responses、Anthropic Messages 与 Gemini Native 已接入原生流式请求、工具调用、取消与用量；云同步尚未接通，聚合不自动故障转移。
- 方案生成界面、八步后端、引用白名单、排期、硬里程碑校验、取消恢复、局部重生成与采用已接入。
- 知识地图、真实有向最短路径、阅读状态、测评证据和补学任务已接入。
- 学习空间、逐单元讲义、实时生成、取消恢复、历史版本、阅读/收藏/批注及原件导出已接入。
- Agent 工作台、全局导师与任务中心使用真实 commands/events；会话、工具结果、记忆审批、scratch 提升、取消恢复和累计 Token 预算由原生后端提供。
- 间隔复习支持真实卡片管理、暂停恢复、四档反馈、历史保持率、到期日历与知识节点证据。
- 选择与填空练习按已采用方案、阶段和原文引用生成，支持原生判分、延期／仅提示反馈、收藏、错题导出、历史、取消恢复与实时模型输出。
- 简答与论述题按持久化 rubric 分项评分，返回得分、依据与原文引用；支持混合题型、异步取消恢复、失败重试和无效评分拒绝，不按答案长度伪造评价。
- 变式练习只从真实错题生成，保持题型、方案与知识节点，保存原题血缘；达到真实掌握阈值后联动更新原错题，并区分手动标记与变式通过。
- 模拟考试支持真实题型组合、1–240 分钟绝对截止时间、建议通过百分比、交卷与历史。交卷前隐藏答案；未作答明确按 0 分计，未判分的作答不得伪造为完成。
- KB/Wiki 检索、原文引用问答、字符与行号定位、历史删除与原子清空已接入原生后端，并通过真实材料与本机回环模型的无界面验收。
- URL 抓取、外部资源检索、视频播放、导出和分享仍待接入；Agent 网络工具会明确返回不可用。
- 扫描件 OCR、音视频识别、云同步、社区和安全能力尚未全部接通。

这些页面的合成内容或演示操作不代表真实外部服务已经可用。

## Brand Commitments

产品名：知舟 Deep Tutor。中文界面。使用用户指定的 Impeccable 设计方法。

## Evidence on Hand

页面内学习记录与课程内容均为用于界面演示的合成数据，不构成真实用户成绩或学习效果声明。

## Product Principles

1. 下一步行动优先于信息堆积。
2. 掌握度必须有练习、复习或项目证据。
3. AI 优先提示与反馈，而非替代学习者完成。
4. 所有关键操作可见、可撤销或可恢复。
5. 完整功能不能牺牲阅读、响应式和无障碍体验。

## Accessibility & Inclusion

支持键盘操作、可见焦点、减弱动态效果、字号与高对比度设置，并保证移动端基本可用性。
