## 新增

- 双击侧边栏会话行就地重命名；重命名对话框可以按需自动起标题 (#12977, #11591)
- 没有配置任何模型服务也能启动，直接打开连接引导 (#12966)
- 项目或会话所在磁盘快满时发出提醒，默认开启，只提醒不清理文件 (#12960)
- 终端界面向终端报告工作中、等待你、已完成的状态 (#12976)
- 已完成的会话可以在「进行中」列表里多留一段时间，默认关闭 (#12957)
- 侧边栏标出保存在 1.x 里的会话，终端恢复列表标出未查看的会话 (#12405, #12587)
- 用 / 调用技能时显示为紧凑的技能块；工具调用的 JSON 输入带语法着色 (#12972, #12969)
- 变更列表里可以暂存和取消暂存文件 (#12923)
- 应用图标显示未读的任务完成数，并换成扁平的新图标 (#12922, #12897)
- 新增「清白蓝」「茶绿」配色，主题包可以声明密度和圆角 (#12932, #12513)
- 图标栏有新建会话按钮；点标题栏的文件夹标记可以打开项目文件夹 (#12891, #12857, #12288)
- 对话里的文件链接可以在工作台打开；文件菜单可以把文件或文件夹加入对话 (#12910, #12877)
- 远程机器收进一个可折叠的行，会话树各层级更容易分清 (#12878, #12905)
- 第二次按 Esc 才会停止正在运行的回合 (#12859)
- 扩展界面支持样式字段、可编辑草稿、地图对比仪表盘和非阻塞动作 (#12830, #12854, #12876, #12896)
- 已安装的包可以按功能搜索、显示贡献类型、复制调用方式，安装预览显示解析出的提交 (#12065, #12117, #12070, #12075, #12098)
- 可以查看子代理的技能声明，并搜索 MCP 服务器的工具清单 (#12102, #12085)
- 发现 WSL 发行版并探测其中一个 (#12595)
- 手机页可以添加到主屏幕；已配对的手机在重启后保留，设置里有开关 (#12591, #12440)
- 发布 Linux arm64 的 .deb 和 .rpm 安装包 (#12914)
- 本机 stdio 的 MCP 服务器能收到工作目录和宿主的只读状态 (#12967)
- MCP 服务器在运行中增删工具并发出通知时，工具目录会自动刷新 (#12138)
- 可以关闭宿主对已改动回合的检查 (#12860)
- 从右到左的文字块按自身方向显示 (#12118)
- 工作台浏览器标签菜单新增「关闭右侧浏览器标签」，可用键盘打开 (#12557)

## 变更

- 版本页只保留最新的几个早期版本，其余折叠到一个按钮后 (#12982)
- 会话列表统一为单行省略，批量选择入口移到「这台机器」的更多菜单 (#12935)
- 桌面侧栏统一用分隔条操作；品牌标识统一为正式字标 (#12918, #12936)
- 计算机操作改用 CUA Driver (#12937)
- 对话里的「执行过程」改成淡色一行，展开后的头部会吸在顶部 (#12954, #12944)
- 标题栏的会话标题紧挨项目名；分支按钮悬停的形状与相邻按钮一致 (#12955, #12971)
- 模型列表只留设置页的一条滚动条，显示别名输入框跟随主题 (#12979)
- 已安装的技能按来源分组 (#12329)

- Windows 上 Git Bash 探测挂起时重试一次，并正确显示回退用的终端路径 (#12887)
- 只发 /技能名 时，历史里记录的是你输入的原文 (#12890)
- MCP 工具重名会被拒绝，原始标识在各条路径里保持一致 (#12889, #12893, #12892)
- 子代理状态帧在客户端落后时不再丢失 (#12888)
- 文件预览会先检查目标是否允许访问，并先经过 PreToolUse 钩子 (#12115)
