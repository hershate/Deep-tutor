本版加入从任意回复分支会话、会话批量操作、模型显示别名和 MCP 工具定义变更审批，并修复长对话里拖选文字卡死、重载后丢失撤销入口等问题。

## 新增

- 可以从任意一条回复分支出一个独立的新会话 (#12770)
- 会话行上有快速归档和删除；可以多选本地会话做批量操作 (#12775, #12807)
- 把文件夹拖到侧边栏即可添加为项目，项目右键菜单可以打开项目操作 (#12776, #12324)
- 从上下文环和检查器就能压缩上下文 (#12777)
- 对话导航旁显示当前计划 (#12803)
- 浏览器面板新增宽屏模式，打开时仍能看到对话；浏览器页面可以逐个或批量关闭 (#11762, #12806)
- 文件面板右键增加「复制路径」和「复制引用」，名称里含冒号或以反斜杠结尾而无法表示成引用时会禁用后者 (#12818, #12842)
- 可以给每个模型设置显示别名；添加来源前可以批量检测模型 (#12821, #12835)
- 模型偏好里可以设置联网搜索使用的模型 (#11761)
- MCP 服务器的工具定义变更后，需要重新批准才会启用 (#12829)
- 回退之后对话顶部显示持久的撤销提示，可以关闭，重载后仍在 (#12831, #12559)
- 可以在右键菜单里引用选中的回复文字 (#12836)
- 发送快捷键成为统一的偏好设置 (#12837)
- 反馈表单里可以直接打开日志文件夹；反馈对话折叠显示并保留未读状态 (#12768, #12802)
- 正在使用的版本被撤回时，应用会告知用户 (#12769)
- 工作台「+」按钮会显示启动器，从导航打开聚焦会话的文件 (#12826, #12832)

## 变更

- 会话标签页改为按需开启 (#12841)
- 项目里置顶的会话排在最前并带标记 (#12845)
- 默认浅色主题的层次重新调整；视图标签与页面色调一致 (#12793, #12782)
- 对话壁纸下的文字光晕可以配置 (#12839)
- 当前使用的模型在输入框的选择器里排第一 (#12801)
- 手机窄屏上未输入时的输入框更紧凑，并保留分支标识 (#12800, #12813)
- 左侧图标栏的图标与对应设置分区一致；设置页打开时侧边栏开关仍可用 (#12753, #12798)
- 首屏改用 1.9 MB 的核心字体子集；对话导航条每个可区分位置只画一个标记 (#12766, #12767)
- 多个会话共用一个工作区时，写入改用乐观租约 (#12772)
- 没有声明检查的项目里，写过文件的未识别命令不再免除验证 (#12848)

## 修复

- 长对话里拖选文字会卡死：选区经过的远处块改为按对话原文保留，1200 轮对话里跨屏选择从数十秒降到约 0.1 秒；这些中间块复制出的是对话原文，不再带界面标签 (#12850)
- 一个超过 128 个字符的 MCP 工具名会让整个会话的每次请求失败：现在只缩短工具名部分 (#12849)
- 密集的时间线信号可以逐个查看 (#12815)
- 压缩对话时转录区不再跳动 (#12783)
- 停放的浏览器页面再次显示时会重新附着，不再留下空白 (#12778)
- Windows 上替换插件目录时不再重命名被监视的目录 (#11822)
- 反馈里正确报告 Windows 11 的产品线 (#12734)
- 没有任何对话的文件夹现在返回空的会话列表 (#12744)
- 终端界面里补全菜单中按 Esc 会同时停止正在运行的回合 (#12761)
- 记忆改名时先下线旧名再发布；归档记忆恢复失败后可以重试，索引与归档保持一致 (#12785, #12816, #12819)
- 自动召回的记忆在轨迹里记录是被条数还是字符预算截掉的 (#12843)
