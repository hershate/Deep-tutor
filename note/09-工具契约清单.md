### 1.6 verify_url — Python（349 行，独立工具 + 内部被 search_resources 复用）

- 手动跟随重定向 ≤5 跳（_REDIRECT_STATUSES）；**SSRF 防护**：拒绝解析到私网/环回/链路本地 IP 与云元数据主机（169.254.169.254 等，UnsafeRedirectError）；robots.txt 缓存 1h（_robots_allows）；只读前 16KB 正文（`_analyze_body` 判登录墙/空壳/拦截页关键词）；snippet ≤400 字符。
- 结果缓存：ok 24h / err 1h，容量 4096（`_cache_get/_cache_put`）；超时重试 1 次。
- verified ∈ {ok, uncertain, invalid}。

## 5. 工具执行统一语义（loop.py，详见 [03](03-生成流水线.md) §3）

```
run_tool = 取消检查 → LLM/Python 分流 →
  [LLM] system(skill→inline→default) + user(args+upstream 清洗) →
        瞬态退避重试 → JSON 提取 + pydantic 校验 → 失败修复重试≤3 →
        post_process → ok | degraded(repaired/error)
  [Python] asyncio.wait_for(func, timeouts.parse=900s)
→ metadata(duration/tokens/cost) → ToolOutput
```
