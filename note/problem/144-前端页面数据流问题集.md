## P3

### 144#1 只读分享页（#shared）期间拖放导入资料完全无反馈，真实写入静默发生

- 位置：`desktop/src/App.tsx:271-290`（拖放 effect，守卫仅 `!ready || loginRequired`，
  无 `page !== 'shared'` 判定）；`App.tsx:450-455`（`page === 'shared'` 早退分支只
  渲染 shared-topbar + SharedPlan，不含 import-progress chip 与 ToastStack）；对照
  `App.tsx:518-519`（chip 与 toast 仅在主 app-shell 渲染）。
- 传递链条：①用户在 `#shared` 只读预览停留，此时 ready=true、loginRequired=false，
  拖放 effect 处于挂载状态；②拖入一批文件 → `importMaterialPaths` 按批真实写入
  资料库并逐批 `setImportProgress('正在导入资料 N/M')`、终态 notify；③shared 分支
  既不渲染 import-progress 也不渲染 ToastStack——进度与结果提示全部不可见，导入
  静默完成，用户仅在事后进资料库才会发现。
- 影响范围：受影响=分享预览页期间的一切窗口拖放导入（批量资料/ZIP 均中招）；
  不受影响=主界面内拖放（chip+toast 正常）。损害性质=真实数据写入零反馈，与
  只读页语义冲突。
- 修复方向：拖放 effect 增加 `page !== 'shared'` 守卫（与 Ctrl+K 的 136#6 同口径，
  page 经 ref 取最新），或在 shared 分支补渲染 importProgress 与 ToastStack。

### 144#3 模拟考试填空题「保存答案」后作答立即从界面消失，无任何回显

- 位置：`desktop/src/components/ExamWorkspace.tsx:148`（submit 成功后
  `setSelected(null); setDraft('')`）；`ExamWorkspace.tsx:216`（fill 输入恒
  `value={draft}`，无 `answer.response` 回退）；对照同文件 `:217`（short/essay
  显式 `value={recorded && typeof answer?.response === 'string' ? answer.response
  : draft}`）与 `:50`+`:212`（choice 经 selectedValue 保留已选项高亮）；再对照
  针对练习页 `Practice.tsx:263`（fill 提交后不清空 textAnswer）。
- 传递链条：①考试中填空题输入并点「保存答案」；②`setDraft('')` 清空本地草稿，
  input 变空并禁用（recorded=true）；③fill 是考试视图里唯一没有 answer.response
  回退的题型——已保存的作答立即不可见；交卷前 `answer.status==='done'` 不命中
  任何反馈块，仅进度条 +1 可作间接证据；翻到别题再翻回时（effect 重挂）又会从
  draftByQuestion 读回提交前文本——前后显示不一致。
- 影响范围：受影响=模拟考试 fill 题；不受影响=同页 choice/short/essay（均有
  回退）、针对练习页 fill（不清空）。损害性质=考试复核链路断点，考生无法确认
  作答已保存。
- 修复方向：fill 的 value 与 short/essay 同款回退：`value={recorded && typeof
  answer?.response === 'string' ? answer.response : draft}`。

- 修复方向：catch 分支补 `if (ticket !== seq.current) return` 同款守卫；App
