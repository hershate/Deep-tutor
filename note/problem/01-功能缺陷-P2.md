## 1. 同步"清除已保存凭据"开关在 S3 与 WebDAV Basic/Bearer 下必然失败，旧凭据被原样回写

- 前端：`desktop/src/components/SyncPanel.tsx:52`——勾选 `clearCredentials` 后把
  `password/accessKey/secretKey` 置空字符串提交；`SyncPanel.tsx:144` 开关文案
  "保存后删除系统密钥库中对应的同步凭据"。
- 后端：`desktop/src-tauri/src/backend/sync/mod.rs:350-367`——S3 分支先按空串删除
  access/secret 两把 key，随后第 367 行 `credentials(service, &config)?` 立即强制要求
  两把 key 均存在（缺失返回 `sync_credentials_missing`）；
  `sync/mod.rs:369-379`——WebDAV 非 `none` 认证同样在删除后强制校验；
  `sync/mod.rs:394-397`——失败路径 `restore_credentials` 把刚删除的旧凭据恢复回密钥库。
- 影响：S3 档案勾选"清除凭据"后保存必报"S3 Access Key 未配置"，WebDAV Basic/Bearer
  报"WebDAV 凭据未配置"，且密钥库旧凭据被恢复、配置未保存——清除功能完全不可用，
  与开关文案相反。仅 WebDAV + 无认证组合不受影响。

## 2. 路由 failover 第二次切换起前端丢失上游请求 id，Agent 直播输出冻结

## 10. [P1] Modal 焦点 effect 依赖不稳定的 onClose，全部 44 处弹窗的文本输入被焦点抢夺阻断
- 前端：`desktop/src/components/UI.tsx:47-55`——effect 依赖 `[open, onClose]`，打开时 20ms 后 `ref.current?.focus()` 把焦点移到 modal 容器；全仓 44 处 `<Modal>` 的 onClose 全部是每次渲染新建的内联箭头函数（App.tsx:286/289/292/297、Plan.tsx:167-170、Projects.tsx:162-165、ProviderHub.tsx:381/384、Library.tsx:263 等）。
- 机制：弹窗内每输入一个字符 → 父组件重渲染 → onClose 引用变化 → effect 重跑 → 20ms 后焦点从输入框移走 → 后续击键丢失；中文 IME 组合也被打断。
- 影响：笔记编辑、Plan 添加任务、Projects 提交成果、Community 发帖/预约、供应商编辑器（含 API Key 输入）、Review 建卡、快速记录、全局搜索等所有含文本输入的弹窗，实际一次只能输入一个字符。

## 19. schema 指纹门控使"代码侧 schema 演进"对既有库永不触发迁移——下一次加列/加表必然漏掉全部老用户

## 20. 旧根库一次性复制非原子：中途崩溃留下截断的用户库，无完整性校验、永不自动重拷

## 26. 五处回环测试服务器的 gate 等待无超时，断言失败即挂死整个串行套件
