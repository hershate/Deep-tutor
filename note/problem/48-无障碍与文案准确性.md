### 48#1 AgentCenter 发送按钮纯图标且无可访问名称——读屏用户不知其用途

- 位置：`desktop/src/pages/AgentCenter.tsx:117`（主审亲验）；对照同型 `components/TutorPanel.tsx:46` 有 `aria-label="发送问题"`

- **传递链条**：① 读屏用户 Tab 至该钮 → ② 播报仅「按钮」→ ③ 无法得知这是发送（Agent 对话主操作）→ ④ 同页面 textarea Enter 也可发送，但键盘路径上该钮为唯一显式动作入口。属遗漏而非设计（TutorPanel 同型有标签）。
- **影响范围**：屏幕阅读器用户的 Agent 核心操作。修复：`aria-label="发送"`（一行）。

### 48#2 深色主题下 amber/red/blue Badge 被抹成与 neutral 完全相同——状态色调通道丢失

### 48#3 「已完成阅读」按钮实为「再次保存并进入下一阶段」——状态文案放在动作钮上

- 位置：`desktop/src/pages/StudyRoom.tsx:265`（主审亲验：三元切换文案，onClick 恒为 `completeAndContinue`）。
- **传递链条**：① 用户读完当前阶段并点「完成并继续」→ ② 阶段标记 completed，按钮文案切换为「已完成阅读」——但 onClick 仍绑定 completeAndContinue → ③ 用户误以为这只是状态展示（或以为能点它「取消完成」）→ ④ 再点一次：重新保存 done=true 并立即跳到下一阶段——意外离开当前内容。
- **影响范围**：所有完成过阶段的学习室用户——状态文案放在动作钮上造成双重误解（不可点/可撤销皆错）；无数据损害（重保存幂等）。修复：状态用 Badge 展示，按钮恒为「完成并继续」或完成后禁用。

### 48#4 档案编辑弹窗对 legacy weeklyHours 显示空选且保存必败

- **影响范围**：存量非标档案用户编辑必败。修复：弹窗复用主区块的回退 option 逻辑。

### 48#5 熔断数字输入不前端校验——清空 blur 提交 0，后端整单拒绝且不回显原因

- 位置：`desktop/src/components/ProviderRouting.tsx:75-77`（主审亲验）；后端 `providers/routing.rs:352-358`（failures 1..=10/cooldown 10..=600/timeout 5..=300/retries ≤3）；对照 UsagePanel.tsx:63、Community.tsx:159 的 onChange 钳制做法。
- **传递链条**：① 用户在熔断设置里清空输入框（或手输 0/越界值）→ ② HTML min/max 属性不约束手输，blur 时 `Number('')===0` 直接作为新值 → ③ 保存把四字段整单提交 → ④ 后端逐项校验发现 0 越界 → ⑤ 整单拒绝 `invalid_circuit_settings`，页面只弹通用错误横幅——不指出是哪个字段、输入框也不回显原因。
- **影响范围**：手调熔断参数的用户——一次手滑导致整单（含其他正确字段）保存失败且无从定位。修复：blur 时钳制到 min/max 或逐字段报错。

### 48#6 单选用 checkbox 实现——「可用模型」默认模型被读屏播报为复选框组

- 位置：`desktop/src/pages/ProviderHub.tsx:390`（`checked={form.defaultModel === model}`）。
- **传递链条**：① 供应商编辑器「可用模型」列表渲染 `<input type="checkbox" checked={默认===model}>` → ② 读屏把它播报为一组复选框（多选语义）→ ③ 用户勾选 B 时 A 被悄悄取消——违背复选框「可多选」的可访问语义 → ④ 读屏用户无法理解为什么「勾选一个会取消另一个」。
- **影响范围**：屏幕阅读器用户配置供应商时；鼠标/键盘用户功能不受影响（交互本身正确）。修复：改 radio（同 name 分组）+ 默认项标注。全仓唯一实例。

### 48#7 展开控件全仓零 `aria-expanded`——三处折叠钮状态不可编程感知

- 位置：`Community.tsx:149`（「N 条回复」）、`:154`（「阅读完整社区公约/收起」）、`StudyRoom.tsx:244`（课程目录）。
- **传递链条**：① 用户点击折叠钮 → ② state 翻转 expanded → ③ DOM 出现/消失回复列表或目录，但按钮自身的 `aria-expanded` 缺失（全仓 grep 0 处）→ ④ 读屏只播报按钮文案，不知当前是展开还是收起、点击后会发生什么。
- **影响范围**：读屏用户在社区页与学习室目录的导航；三处均为常用路径。修复：`aria-expanded={expanded}` + `aria-controls` 指向列表容器 id。

### 48#8 五处输入框仅 placeholder 无可访问名称

## 正向结论（六轴核对过、无问题）

- **数字/时间文案 21 项与后端逐项全对**：8 份资料、84 天（含今日）、1440 分钟、复习首间隔 2/5/12 天与 10 分钟、保持率 60/80/100、40 秒/张、200 张/200 条截断、25 步/单步 8 工具、产物 24 小时、提前 15 分钟提醒、50MB、每周 1-80h、时长 1-10080、重生成上限核算、24h 同步/10 版本、分享 7-365 天、考试 1-240 分钟与 1-100 通过线、配额 1-100000、maxTokens 16384、费率 1e6、预约 10-240 分钟。
- **role="alert" 35 处全部用于错误**，成功回执一律 role="status"；toast error/info 双通道分档（5.2s/3.2s）。
- **IconButton 强制 label**、Modal 统一 dialog/aria-modal/焦点圈禁/还原、Esc 分层栈、skip-link、`:focus-visible` 3px。
- **无 clickable div/span**（全仓 0 命中）；热键无冲突；Review 快捷键正确排除弹层与输入焦点。
- **相对时间**（刚刚<60s/分钟/小时/天/30 天切日期）无边界文案缺陷；空态引导全部指向真实功能；取消/保存类按钮语义逐条相符。
- **减动效双通道**（类 + prefers-reduced-motion）正确终止全部动画；**大字模式** zoom 等比 + 交互件 min-height 化，无布局破坏点。
- **表单**：label 隐式关联为主、fieldset/legend 用于题型、数字区间前后端 21 项一致。
