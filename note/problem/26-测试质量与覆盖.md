# 26 号 · 测试质量与覆盖（P2 × 1 + P3 × 5）

> 第十一轮对 181 个测试（34 文件）的断言强度审计。总体结论：回环 TCP 服务 + 请求计数 +
> 独立哈希重算使绝大多数绿灯有真实证明力，13 项关键决策中 11 项有直接可断言到错误码的
> 覆盖；问题集中在真实系统密钥库的静默跳过与个别弱断言。

## P2

### 26#1 真实系统密钥库探针测试在无 keyring 环境"静默跳过仍计为通过"，门禁全绿可能零覆盖真实 keyring

- 位置：`desktop/src-tauri/src/backend/security/tests.rs:496-508`；同样模式 `providers/tests.rs:1634-1656`
- 证据：
  ```rust
  if backend.set(&id, "probe-value").is_err() {
      eprintln!("skipped: 宿主环境没有可用系统密钥库");
      return;   // 无 #[ignore]、无跳过计数、无失败信号
  }
  ```
  套件中其余测试全部用 MemoryCredentials；仅这两个探针真实 SystemCredentials。keyring
  不可用的主机上，真实 keyring 的 set/get/delete 链路（12#16 修复声称守护的
  "persists_across_entries"性质）在门禁中零覆盖，仍显示 181/181 全绿。
- 修复方向：跳过时置全局标记并在套件尾部 assert（或 cargo 输出区分 skipped），
  CI 提供可用 keyring 或显式允许跳过。

## P3

### 26#2 期望值与实现同源：分享 token 哈希断言自证

- 位置：`desktop/src-tauri/src/backend/sharing/tests.rs:142-151`
- 证据：`assert_eq!(hash, token_hash(token))` —— `token_hash` 正是被测实现用的同一函数，
  实现退化为恒等函数（明文入库）此断言仍通过。缓解：security/tests.rs:93-103 有独立
  `assert_ne!(stored, raw)` 断言兜底；此条属冗余误导而非漏洞。

### 26#3 keyring 失败 → typed error 链路只在 mock 后端验证

- 位置：`desktop/src-tauri/src/backend/providers/tests.rs:1596-1619`
- 证据：故障注入点 `MEMORY_CREDENTIAL_FAIL`（providers/mod.rs:157-166）只挂 Memory 后端；
  真实 SystemCredentials 的 set/get 失败映射从未注入验证——结合 26#1，无 keyring 主机上
  该链路完全无真实覆盖（触发侧的事务中止补偿逻辑覆盖是真实的）。

### 26#4 成功路径的"导入预演不落盘"无直接断言

- 位置：`desktop/src-tauri/src/backend/backup/tests.rs:205-220`
- 证据：`preview_full_backup` 后紧跟 `import_full_backup`，两步之间无"目标未被 preview
  改动"断言。失败路径的预演不落盘有直接断言（:405-426、:476-497）；成功路径靠
  dry_run 实现而非断言保证。

### 26#5 进程级静态量依赖 `--test-threads=1` 串行，套件无法并行

- 位置：`providers/mod.rs:157-166`（MEMORY_CREDENTIAL_FAIL 全局一次性开关）、`store.rs:24`（MIGRATION_RUNS 计数，store.rs:1256-1267 断言依赖无并发打开）、`web/mod.rs:37-42`（SEARCH_ENDPOINT 可替换全局，4 处使用均持锁）、`sync/mod.rs:31`（DEFER OnceLock，借用方均持 TEST_LOCK）
- 证据：现状在门禁参数下无顺序依赖 bug；这些静态量是隐含契约，新增测试忘加锁会静默
  互扰。Makefile/CI 已显式 `--test-threads=1` 并注释原因，维持现状可接受，记录为约束。

### 26#6 setup 吞掉终态结果（`let _ = wait_terminal(...)`）拉远失败诊断

- 位置：`desktop/src-tauri/src/backend/learning/tests.rs:603,689,780,857,917,993`
- 证据：wait_terminal 对 failed 终态不报警即返回；若管线静默 failed，后续断言间接失败
  但离根因更远。属诊断性/可读性问题，非假绿。
