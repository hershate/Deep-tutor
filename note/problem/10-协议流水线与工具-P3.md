## 协议层（providers）

### 1. OpenAI Chat 单上游重试不含 incomplete_stream，其余三协议含——跨协议重试语义不一致
- `openai.rs:727-734` 仅四码可重试；`protocol.rs:174-181`（Responses/Anthropic/Gemini）额外含 incomplete_stream；`routing.rs:592-601` 路由层也含。12/18 预设走 OpenAI Chat，直连模式"流中断且零输出"立即失败不重试。

### 2. 重试之间无任何退避间隔，429 后立即原样重发
- `openai.rs:702-746`、`anthropic.rs:129-292`、`responses.rs:102-269`、`gemini.rs:126-236`、`routing.rs:953-1079` 均无 sleep——速率限制场景第二次大概率再撞 429，重试预算浪费。

### 3. [待确认] reasoning 增量仅识别 reasoning_content，reasoning 字段被丢弃
- `openai.rs:933/456-460`；OpenRouter（18 预设之一）把推理增量放在 delta.reasoning——思考流不进 reasoning 通道（正文不受影响）。

### 4. "token 上限截断"跨协议语义相反：OpenAI Chat 视为正常完成，Responses 视为失败
- `openai.rs:888-890`（finish_reason=length 仅记录，status=done）vs `responses.rs:236-240`（response.incomplete 直接报 incomplete_stream 整步 failed）。Agent 每步 max_tokens=4096。

### 5. Gemini 分支不处理流中 error 事件，真实错误退化为 incomplete_stream
- `gemini.rs:142-223` 无 error 分支（对比 responses.rs:241-253、anthropic.rs:262-276）；流内错误（配额等）被忽略后报泛化"流式响应在结束标记前中断"，诊断信息丢失。

### 6. OpenRouter 预设默认模型 auto 不是有效 id（应为 openrouter/auto）
- `ProviderHub.tsx:21`——models:['auto',...], defaultModel:'auto'；选该预设后默认用法全部 400（model not found），须手动改模型名。

### 7. Azure OpenAI 预设任何填法都无法工作
- `ProviderHub.tsx:26` 占位主机保存即 DNS 失败；换真实资源名后路径结构错误（代码拼 …/chat/completions，Azure 要求 …/openai/deployments/{d}/...）；api-version 查询串被 `openai.rs:210-215` 全局禁止。18 预设中唯一"看似支持实则物理不可达"且无说明。

### 8. [待确认] OpenAI Chat 分支完全不消毒工具名，与其余三协议不一致
- `openai.rs:506-509/999-1003` 原样序列化带点名工具；OpenAI 官方强制 `^[a-zA-Z0-9_-]{1,64}$`——严格端点第一步即 400。[待确认各兼容端是否强制]

### 9. 架构文档 §6 mermaid 把 half_open 描述为"放行调用"，实际并发请求被 circuit_probing 拒绝跳过
- `docs/architecture/02:225` vs `routing.rs:634-637`（half_open 返回错误并 continue）、`:653-664`（仅 CAS 赢家放行）——防惊群设计未在文档表达。

### 10. 架构文档 §6 候选循环/熔断/故障转移未标注"仅 routing 模式生效"
- `docs/architecture/02:214/219/222` 读起来三种模式都经过该链路；实际 `routing.rs:934/972/1065` 三处 `mode == "routing"` 判定——direct/aggregate 零熔断零 failover（与 UI 文案一致、与文档不一致）。

## 八步流水线（learning）

### 11. 方案生成重试次数文档"2 次"实为共 2 次尝试（1 次重试）
- `docs/architecture/02:137/155` vs `pipeline.rs:214`（`for retry in 0..2`）、`lecture.rs:579` 同构。

### 12. JSON 解析容错仅覆盖"整段以 ``` 开头"的围栏，无截断修复；截断型失败重试时 max_tokens 不变
- `pipeline.rs:177-193`——围栏前有说明文字/尾随逗号/被截断一律 invalid_model_output；`:219-229` 重试沿用相同参数，截断类失败大概率原样复现，两次后整案 failed。

### 13. 讲义单元重试提示不带具体校验错误，模型无从修正引用类失败
- `lecture.rs:598-603` 仅追加"上次输出未通过校验"；对比方案步骤重试附 last_error.message（pipeline.rs:222-229）。讲义最常见失败恰是 citation_mismatch。

### 14. 讲义生成复用"学习方案生成器"系统提示，任务身份错位
- `lecture.rs:593` 使用 `pipeline::MODEL_SYSTEM`（"你是…学习方案生成器"，pipeline.rs:9），但场景是逐节点撰写讲义。

### 15. 每个讲义单元的提示重复注入全部资料全文，成本随单元数线性放大
- `lecture.rs:573-576`——prompt 尾部为全部 sources JSON 全文（≤192KB），每阶段 3–6 单元 × 全方案最多约 100 节点各重复发送；无单元级筛选/截断。输入 token 成本最高放大 ~100 倍。

### 16. [待确认] 图谱步骤 8192 输出 token 上限与"最多 100 节点、每节点多引引用"矛盾
- 提示允许 100 节点（pipeline.rs:141）、校验接受 1..=100（validate.rs:19-24），但输出上限 8192 tokens（pipeline.rs:450）——合规输出可估算超限 → 截断 → 解析失败 → 同参重试 → 整案 failed。

### 17. schedule/node 任务表与 kv tasks 无删除同步（当前潜在）
- 两表无按任务删除路径（仅 clear_all）；kv 任务删除后周视图仍计入分钟（planning/mod.rs:124-149 有"已删除任务"兜底文案但清理联动未实现）；`add_knowledge_task` 去重键在任务删除后仍命中残留行，该节点永久无法重建补学任务。当前前端无删除入口故暂无触发路径。

## Agent 工具与网页抓取（agent/web）

### 18. agent_memory 是 agent 域唯一无条数配额的持久写入口
- `store.rs:302-319` ensure_quota 无 agent_memory 分支；`tools.rs:707` 直接 upsert。写入受审批门控，属加固缺口。

### 19. DDG 检索无 region 参数、非浏览器 UA、无限流识别与退避
- `web/mod.rs:315-318`（仅 q 参数）、`:148-156`（固定 UA）、`:171-188`（403/429 与普通错误同报）——触发限流后模型立即重试只会加固封锁；中文查询默认美区结果。

### 20. 检索候选验证循环无尝试上限，rejected 不去重不限长
- `web/mod.rs:323-341`——候选普遍不可达时 20–30 次串行抓取（分钟到十分钟级），无中间事件；rejected 无上限膨胀工具结果。

### 21. 正文提取无密度启发式：空白折叠、inline 断词、注释泄漏、导航混入
- `web/html.rs:132-134`（split_whitespace 折叠全部换行）、`:167-168`（每文本节点后插空格断词）、`:171-184`（含 > 的注释泄漏）、nav/footer 未剥离——web.fetch 送模型的是无换行混导航单行文本；import_webpage 落库资料同构，knowledge 引用"第 N 行"对网页资料恒为 1 失义。

### 22. 检索选择器硬编码，DDG 改版即检索整体失效（风险登记）
- `html.rs:220/233-234` 仅认 result__snippet/result__a；无选择器版本化或降级解析。有优雅失败兜底，非现行缺陷。

### 23. knowledge ask 无聚合输入上限：8 份 × 16000 字 = 12.8 万字符单请求
- `knowledge/mod.rs:24/539-542/202`——仅逐份截断，无跨资料总量控制（对照方案生成 192KiB 总量闸）——全选时中文 13–19 万 token，可超 128K 上下文使问答必然失败，用户无引导。

### 24. quote 定位失败无降级：单条引用问题即整题 failed
- `knowledge/mod.rs:598-607`——任一 citation 的 quote 非逐字匹配即 citation_mismatch 整次作废（输出费用沉没）；对比检索路径 search_hit 用 .ok() 优雅降级（:339）；locate 取首次出现位置，多次出现无歧义消解。

### 25. 网页导入正文静默截断 256KiB 无标记；超长标题站点抓取成功后导入必败
- `web/mod.rs:17/274` 截断事实不落 warning（PlanGenerator.tsx:182 仍称"已保存真实正文"）；`web/mod.rs:266-270` 网页标题无长度钳制，>200B 即 `invalid_title` 导入失败，错误文案与网页场景脱节。
