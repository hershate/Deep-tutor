### 2. 五处用 `Date.now()` 生成集合 id（同时充当列表 key）
- 证据：`App.tsx:194-195`、`Dashboard.tsx:49`、`Plan.tsx:106-107`、`Library.tsx:203`、`Projects.tsx:93/104`。

## 导航与无障碍

### 4. skip-link 把路由 hash 覆写为 #main-content
- 证据：`App.tsx:268`——`<a href="#main-content">`。
- 影响：按一次 skip-link 后刷新会回落"今日"页而非当前页。
- 传递链条：键盘/读屏用户按一次 skip-link 后刷新页面 → 根因（`App.tsx:268` `<a href="#main-content">` 把路由 hash 覆写为 #main-content）→ 传导（App.tsx:50 初始化时该 hash 不在 allNav 与 ['settings','shared'] 内，回落 'today'）→ 症状：刷新后从当前页跳回"今日"页，丢失浏览位置。
- 影响范围：功能面：skip-link 与 hash 路由初始化（全部页面可达性）；触发条件：默认命中——按 skip-link 后刷新即触发（键盘用户高频路径）；受损面：可用性/无障碍。
