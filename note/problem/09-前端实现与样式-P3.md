# P3 前端实现与样式问题（12 项）

第三轮前端内部审计发现。验证通过未列入：全部 useEffect 清理、异步 setState 守卫、
时间解析（38 处 Date.parse 兼容）、NaN/null 防护主体、断点（640 单栏/1024 抽屉）、
focus-visible、reduced-motion 双通道、依赖无冗余。

## React 与状态

### 1. TutorPanel 二次实例化 useBackendState，导师抽屉打开期间双份事件同步管道
- 证据：`TutorPanel.tsx:11` 再次调用 `useBackendState()`（App.tsx:52 已有一份），仅为读 `preferences.hintsOnly`（:20）；hook 每次挂载注册完整 bootstrap 轮询+事件监听+sync 队列。
- 影响：抽屉打开期间每个后端事件触发两次 `events_since + get_app_state` IPC（叠加 06#1 双载），多跑一次完整 bootstrap。

### 2. 五处用 `Date.now()` 生成集合 id（同时充当列表 key）
- 证据：`App.tsx:194-195`、`Dashboard.tsx:49`、`Plan.tsx:106-107`、`Library.tsx:203`、`Projects.tsx:93/104`。
- 影响：同毫秒两次创建产生重复 key/id，后写覆盖先写；概率低但属系统性弱 id 方案（后端无 id 去重）。

### 3. Community 回复草稿全页单一 state，跨帖子串草稿
- 证据：`Community.tsx:18`（单一 reply state）与 :119（每个展开帖共用同一 textarea）。
- 影响：帖 A 输入一半收起、展开帖 B 可直接把 A 的草稿发给 B。

## 导航与无障碍

### 4. skip-link 把路由 hash 覆写为 #main-content
- 证据：`App.tsx:268`——`<a href="#main-content">`。
- 影响：按一次 skip-link 后刷新会回落"今日"页而非当前页。

### 5. Modal/抽屉/专注层均无焦点圈禁（focus trap），aria-modal 与行为不符
- 证据：`UI.tsx:57-62`（role=dialog aria-modal=true 但背景未 inert、无 Tab 循环）；`App.tsx:284/301` 同。
- 影响：键盘用户在弹窗内 Tab 穿越到遮罩背后控件；配合 01#10 焦点抢夺，弹窗键盘操作整体不可靠；PRODUCT.md"支持键盘操作"部分未兑现。

### 6. 大字模式只放大 body 正文，reduce-motion 挡不住显式 smooth 滚动
- 证据：`styles.css:1022-1023`（`.large-text body` 仅一处）vs 全站组件固定 12–14px 数百处；`Settings.tsx:89` 显式 `scrollIntoView({behavior:'smooth'})` 绕过 `.reduce-motion` 的 CSS 覆盖（styles.css:1017）——对比 App.tsx:190 的正确做法。
- 影响：PRODUCT.md:54"字号与高对比度设置……减弱动态效果"的用户预期只部分兑现。

### 7. ProgressBar 把 aria-label 挂在无角色 div 上，读屏不识别
- 证据：`UI.tsx:17-22`——无 role="progressbar"/aria-valuenow/min/max。
- 影响：全站几十处进度条（任务完成度、掌握度、预算、生成进度）对屏幕阅读器不可见。

## 样式与渲染

### 8. 深色模式下报告页趋势折线几乎不可见
- 证据：`UI.tsx:74`（LineChart 默认硬编码 #326c5b 深绿）；`Reports.tsx:18` 未传 color；深色 --bg oklch(0.2)，对比度约 1.8:1，无覆盖规则。
- 影响："掌握度变化"折线图深色下等于不可用。

### 9. 引用未定义 CSS 变量与浅色专用色残留
- 证据：`styles.css:1841-1844`（grade-* 按钮引用未定义的 --danger-soft/--warning-soft/--info-soft，深色下呈亮粉/亮黄浅底）；`:243`（.soft-icon 浅琥珀底无深色覆盖）；`:1648`（.native-chat-output 的 `font:13px/1.75 var(--font)` 引用未定义 --font，整条 font 简写无效）。
- 影响：深色视觉突兀；原生流式输出预览字体规格未生效。

### 10. Plan 页"本周已排 X 小时"输出浮点全精度
- 证据：`Plan.tsx:148`——`{weeklyMinutes / 60} 小时`（同页 :164 与 Dashboard/Reports 均有 toFixed/format，唯此行漏）。
- 影响：70 分钟显示"1.1666666666666667 小时"。

### 11. [待确认/潜在] LineChart 对 ≤1 个点除零产生 NaN 坐标
- 证据：`UI.tsx:80`——`(width - pad*2) / (values.length - 1)`；唯一调用方 Reports.tsx:14-18 已有 `length > 1` 守卫，现网不可达。
- 影响：未来新调用方传 0/1 点将渲染损坏 SVG（length=0 时直接 TypeError）。

## 设计规范

### 12. DESIGN.md 两项无障碍数字系统性未达标、间距节奏脱节、且是零引用孤儿文档
- 证据：`desktop/DESIGN.md:34`"触控目标最小 44px"——styles.css 中 21 个交互控件 20–39px（:153/:181/:338/:453/:468/:473/:499/:611/:715/:1188/:1710 等）；`:20`"辅助文字不小于 12px"——10 处 10–11.2px（:1506 为 10px）；`:27`"4/8px 间距节奏"——实际最常用 10/6/7/5px（非 4/8 倍数约 262 处）；git grep 全部被跟踪文件无任何引用 DESIGN.md。
- 影响：设计规范从未被执行也无人可达；按其验收会产生假阴性。
