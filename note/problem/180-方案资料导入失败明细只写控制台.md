# 180：方案资料导入失败明细只写控制台

## 证据

- `desktop/src/pages/PlanGenerator.tsx:219-241` 批量导入后仅统计失败数量，逐条错误仅执行 `console.error`。
- 同文件 `:239` 给用户提示“明细见控制台”，桌面应用没有面向普通用户的控制台入口。
- `desktop/src/backend/materialImport.ts:58-64` 已有统一摘要函数，可返回失败计数和首个真实后端错误。

## 完整传递链条

新手在方案第一步选择资料 → 文件类型、签名、大小、路径或 ZIP 校验失败 → 后端返回逐文件 `MaterialImportResult.error` → 前端只显示失败总数并把原因写入开发者控制台 → 用户不知道哪个文件为何失败，也无法按提示修正 → 可能反复导入同一坏文件，或误以为必须先上传资料才能继续。

## 影响范围

- AI 方案生成页的文件与 ZIP 导入。
- 无经验用户的错误恢复与对“资料可选”的理解。
- 不影响已导入成功的资料，也不改变资料仍为 0–8 份可选的既有逻辑。

## 修复验收

- 页面内显示首个失败文件名与真实错误，并保留失败总数；不再要求用户查看控制台。
- 同时复用统一导入摘要，保留成功、去重、ZIP 跳过和失败计数。
- 无资料直接继续的入口保持可用；前端构建通过。
