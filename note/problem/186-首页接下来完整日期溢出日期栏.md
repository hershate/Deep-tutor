# 186：首页“接下来”完整日期溢出日期栏

## 证据

- `desktop/src/pages/Dashboard.tsx:34-44` `formatDate` 返回完整的本地化年月日。
- `desktop/src/pages/Dashboard.tsx:51` 将完整字符串直接放入 `.upcoming-date`。
- `desktop/src/styles.css:330-334` 该容器固定为 44px 宽、21px 字号，样式已提供 `:small` 的 12px 月份行，但 JSX 未输出日期与月份的分层内容。

## 完整传递链条

后端返回真实考试或项目日期 → 首页 `formatDate` 转为 `2026年11月12日` 或 `2026/11/12` 等完整文本 → 完整文本进入 44px 宽容器 → 文本宽度超过容器并侵占右侧标题区域或溢出面板 → 375px 窗口和大字模式下对齐失效。

## 影响范围

- 今日页“接下来”中所有考试和项目日期。
- 窄窗口、完整本地化日期和大字模式的排版与可读性。
- 不影响日期数据和点击导航。

## 修复验收

- 日期栏显示独立日号和月份，完整日期保留在可访问名称中；日号、月份均在 44px 栏内。
- 增加 JSX 结构契约检查，禁止再次把完整日期直接塞入该容器。
- 前端生产构建通过。
