### 147#1 导师消息气泡长无空格串横向画出气泡与抽屉

- 位置：`desktop/src/styles.css:515`（`.message-bubble { max-width:94%; … white-space:pre-wrap }`，
  无 `overflow-wrap`/`word-break`；父级 `.message` styles.css:513 为

  消费点 `desktop/src/components/TutorPanel.tsx:57-58`（消息与流式输出，
  内联再写 `whiteSpace:'pre-wrap'`）。
- 传递链条：①用户向知舟导师粘贴长 URL/SHA-256/base64/无空格公式串，或模型
  回答含此类长串；②`white-space:pre-wrap` 只按空白断行，ASCII 长串无断点，
  气泡盒被撑到超过 94% 宽；③文字画出圆角背景，右侧用户消息
  （`.message-user`）从右缘画出，`.tutor-messages`（styles.css:512 仅
  `overflow-y:auto`）出现横向滚动；全局抽屉 `.global-tutor`

  不受影响=消息存储与模型请求本身。损害性质=视觉溢出（「文字超出限定框」
  的高频真实场景：报错排障时粘贴哈希/链接是常见操作）。
- 修复方向：`.message-bubble` 补 `overflow-wrap:anywhere; min-width:0`。
