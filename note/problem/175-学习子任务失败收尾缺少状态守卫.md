# 175：学习子任务失败收尾缺少状态守卫

## 现象与触发条件

主方案或讲义已经终止后，其子步骤或单元的迟到失败仍可把 done 改成 failed，并增加过期事件。171 修复了主行，本项覆盖其子行。

## 传递链条

1. `desktop/src-tauri/src/backend/learning/mod.rs:771-798` 的 `fail_step` 对 plan_id+step_index 无条件更新。
2. `desktop/src-tauri/src/backend/learning/lecture.rs:513-538` 的 `fail_unit` 对 plan/stage/version/unit_index 无条件更新。
3. 恢复路径可能已将运行中子行置 interrupted；正常完成路径也可能已置 done。
4. 子行状态决定恢复时能否复用 `request_id` 和已完成产物；错误改写会造成额外重试或状态不一致。

## 影响范围

影响方案八步流水线、讲义逐单元生成、恢复和重试计数。171 的主行修复不能单独保证子行状态与 outbox 一致。

## 修复验收

只对 running 子行写失败/取消状态；done、interrupted、cancelled 等已有结果不变，未更新时不增加事件。正常失败重试仍可从 failed 重新进入 running。
