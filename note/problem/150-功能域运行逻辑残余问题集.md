### 150#1 报告/日历午夜窗口边界未补零纳秒，首秒数据被字典序比较排除（135#8 家族残留）

- 位置：`desktop/src-tauri/src/backend/reports/mod.rs:221-223`
  （`timestamp()` 直接 `Rfc3339` 格式化——`time` crate 在纳秒为 0 时省略
  小数位，得到 `…T00:00:00Z`）× 三个消费点：
  `:1033-1037`（`calendar_with` `ended_at >= ?1`——84 天热力图窗口
  起点）、`:815-816`（报告窗口 `a.created_at >= ?1` 练习统计 /
  `reviewed_at >= ?1` 保持率）、`:664`（`evidence()` `created_at >= ?1`）、
  `:955`（专注构成 `ended_at >= ?1`）。
- 传递链条：①窗口边界为本地午夜，格式化后无小数位；②列内时间戳几乎
  总带 `.` 小数（亚秒非零），字符串比较 `'.'(0x2E) < 'Z'(0x5A)`——
  窗口首日午夜后第 1 秒内（00:00:00.xxx）落库的行被字典序判为边界之外；
  ③恰在窗口首秒内提交的作答/复习/证据/结束的专注被统计排除。对照
  已修同族：`review/mod.rs:124-138`（`day_start` 显式插 `.000000000`，
  135#8）与 `engagement/mod.rs:599-609`（`tomorrow` 同款补零）——报告
  域这两处漏配；`focus_minutes`/`plan_focus` 走 `parse_time` 时间值比较
  不受影响。
- 影响范围：受影响=报告 4w/8w/学期窗口首秒与热力图最旧日首秒落库的
  记录（概率每行每边界约 1/86400，但确定性排除）；不受影响=其余窗口
  内统计。损害性质=统计口径确定性偏差（边界行为不一致）。
- 修复方向：对齐 `day_start` 范式——窗口起点格式化后补 `.000000000`，
  或改 `parse_time` 时间值比较。
