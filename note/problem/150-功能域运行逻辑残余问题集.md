### 150#1 报告/日历午夜窗口边界未补零纳秒，首秒数据被字典序比较排除（135#8 家族残留）

- 位置：`desktop/src-tauri/src/backend/reports/mod.rs:221-223`
  （`timestamp()` 直接 `Rfc3339` 格式化——`time` crate 在纳秒为 0 时省略
  小数位，得到 `…T00:00:00Z`）× 三个消费点：
  `:1033-1037`（`calendar_with` `ended_at >= ?1`——84 天热力图窗口
  起点）、`:815-816`（报告窗口 `a.created_at >= ?1` 练习统计 /
  `reviewed_at >= ?1` 保持率）、`:664`（`evidence()` `created_at >= ?1`）、
  `:955`（专注构成 `ended_at >= ?1`）。
- 传递链条：①窗口边界为本地午夜，格式化后无小数位；②列内时间戳几乎
  总带 `.` 小数（亚秒非零），字符串比较 `'.'(0x2E) < 'Z'(0x5A)`——
  窗口首日午夜后第 1 秒内（00:00:00.xxx）落库的行被字典序判为边界之外；
  ③恰在窗口首秒内提交的作答/复习/证据/结束的专注被统计排除。对照
  已修同族：`review/mod.rs:124-138`（`day_start` 显式插 `.000000000`，
  135#8）与 `engagement/mod.rs:599-609`（`tomorrow` 同款补零）——报告
  域这两处漏配；`focus_minutes`/`plan_focus` 走 `parse_time` 时间值比较
  不受影响。
- 影响范围：受影响=报告 4w/8w/学期窗口首秒与热力图最旧日首秒落库的
  记录（概率每行每边界约 1/86400，但确定性排除）；不受影响=其余窗口
  内统计。损害性质=统计口径确定性偏差（边界行为不一致）。
- 修复方向：对齐 `day_start` 范式——窗口起点格式化后补 `.000000000`，
  或改 `parse_time` 时间值比较。

### 150#2 单行损坏 kinds_json 使练习历史整体失败（降级口径与他域不一致）

- 位置：`desktop/src-tauri/src/backend/practice/mod.rs:1133`
  （`set.kinds = serde_json::from_str(&kinds)?` 直穿上抛）→
  `list_practice_history`（:1478-1487）逐行读取，一行损坏即整命令失败。
- 传递链条：①practice_sets 某行的 kinds_json 损坏（外部改库/断电部分
  写入/磁盘错误）；②`list_practice_history` 反序列化该行时 `?` 上抛
  `invalid_record`；③整条命令失败 → Practice 页错题/历史区落入
  loadError（有重试按钮，非静默），其余健康行的历史一并不可见。
- 对照：同函数 `detail()` 对 options/citations/node_ids 用
  `unwrap_or_default`（:1228-1234）；learning/projects 域均有跳行降级。
- 影响范围：受影响=Practice 页历史/错题列表（一行坏全表不可见）；
  不受影响=作答、判分与新练习生成（不经该读取路径）。损害性质=单行
  损坏放大为整域不可用（降级口径不一致）。触发面仅限外部损坏。
- 待定夺：对齐跳行降级（记录警告）还是维持 fail-fast。

### 150#3 单行损坏 payload_json 使分享列表与撤销整体失败

- 位置：`desktop/src-tauri/src/backend/sharing/mod.rs:243`
  （`metadata()` 内 `serde_json::from_str(&row.2)?`）被 `list()`
  （:473-488）与 `revoke()`（:499）复用。
- 传递链条：①share_index 某行 payload_json 损坏（外部损坏面同 150#2）；
  ②`list()` 遍历中反序列化失败上抛 → SharePlanDialog 分享列表整页报错；
  ③`revoke()` 对**任何**分享的撤销同样经 `metadata()` 逐行读——坏行在
  遍历序中先于目标行时，更早的有效分享也无法撤销（撤销通道被坏行
  阻塞）。
- 对照：agent/knowledge 域坏行走降级（跳行+告警）。
- 影响范围：受影响=分享列表展示与全部撤销操作（坏行之后的目标）；
  不受影响=已发出链接的只读访问（read_token 路径不走 metadata 遍历）。
  损害性质=撤销能力被单行损坏阻断（后果重于列表失败）。
- 待定夺：至少 revoke 走坏行容忍路径（跳过坏行继续寻找目标行）。

### 150#4 考试倒计时在极旧格式/竞态路径显示「剩余 00:00」

- 位置：`desktop/src/components/ExamWorkspace.tsx:79`
  （`examRemainingSeconds == null` 时 `setSeconds(0)`）而 `:203` 仍渲染
  「剩余 00:00」。
- 传递链条：①`get_practice_set` 返回的考试行 `examRemainingSeconds`
  为 null（旧库行 exam_deadline 已写死后过期、或二次拉卷竞态窗口）；
  ②前端计时 hook 以 0 初始化 seconds；③界面显示「剩余 00:00」——
  考生误以为已截止。后端 `ensure_accepting` 仍按真实 deadline 守卫
  作答，实际不受影响。
- 影响范围：受影响=考试倒计时显示（边缘路径）；不受影响=计时判定、
  交卷与判分（后端权威）。当前主路径不可达（`get_practice_set` 总先
  `start_exam_timer`，practice/commands.rs:22；考试 time_limit 必填
  1-240）。损害性质=显示层误导（边缘）。
- 修复方向：null 时显示「不计时」而非 00:00。
