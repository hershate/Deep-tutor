# 67 · 前端时间与数值显示口径（第二十六轮）

> 审计范围：39 处 new Date、6 处 Date.parse、40+ 处 toLocale*、全部 toFixed/
> 字节/token 显示点；后端序列化逐模块核实（12 模块全部 RFC3339 UTC 带 Z）。
> 主审抽验 N-1（PlanGenerator 直显 UTC 串）属实。

## 先决事实（正向）

后端全部时间字段 `OffsetDateTime::now_utc().format(&Rfc3339)`（带 Z）；community/review 入库前显式 normalize UTC；前端写入侧 toISOString() 同带 Z。**不存在「不带 Z 被当本地时间」的存储路径**；47 号轮后端时区治理后前端显示层无高危时区错误。

## P3

### 67#1（=N-1）PlanGenerator 直显原始 UTC RFC3339 串——全站唯一未本地化时间

- 位置：`PlanGenerator.tsx:307`。
- 传递链条：① 后端 learning_plans.updated_at 以 RFC3339 UTC 持久化（`2026-11-10T08:23:45.123456Z`）→ ② 前端模板直接 `{plan.updatedAt}` 插值（全站唯一未经 toLocaleString/formatDate 的长时间字段）→ ③ 东八区用户在方案生成页步骤 2 看到「最近保存」比实际本地时间早 8 小时，且带 6 位亚秒与 Z 后缀。
- 影响范围：方案生成页运行视图的每条「最近保存」显示（生成/恢复期间高频可见）；用户以该时间判断「方案是不是刚保存的」会得出错误结论。一行改为 toLocaleString 即修，其余全部时间显示点已核对正确。

## 信息性

- 67#2（=N-2/N-7）数字排版不一致。链条：① 同类数字在不同页面分头实现 → ② 有的走 toLocaleString 有的直显/有的换算 MB → ③ 同屏两种排版。影响：token 计数（PlanGenerator 有千位分隔、UsagePanel/AgentCenter 直显）与字节显示（16 处 `X 字节` 一致，但 PlanGenerator:303 全站唯一用 MB、Integrations:107 无分隔）——阅读效率与专业度问题，无数值错误。
- 67#3（=N-3/N-4）locale 三套写法。链条：① 部分调用强制 'zh-CN'、其余用系统默认 → ② 非中文系统下同屏出现两种日期格式 → ③ 当前用户群（中文 Windows）输出一致。影响：仅未来国际化场景的一致性预备；含 Library 相对时间 30 天外切换 toLocaleDateString 未指定 locale。
- 67#4（=N-5）SyncPanel:172 远端时间无解析兜底。链条：① WebDAV getlastmodified（RFC1123）/S3 LastModified（ISO8601）由后端**原样透传字符串** → ② 前端 `new Date(...).toLocaleString()` → ③ 异构服务器返回非标格式（如自定义 header 格式）时 V8 解析失败 → 显示 `Invalid Date`（代码只兜了 null 未兜解析失败）。影响：仅接非标 WebDAV/S3 服务的用户版本列表时间列；概率低、后果为单列显示损坏。
- 67#5（=N-6/N-8）精度与单位标注杂项。链条与影响：复习间隔通知 toFixed(1) vs 列表 toFixed(2)——同一数值两处精度，用户对照困惑（低频）；Dashboard 学习节奏 MiniBars 值为分钟但 SectionHeader 未标单位（同组件在 ReportViews 用小时且有标注）——用户无法从界面得知柱高含义（每页可见）。

## 已核对一致（正向清单）

- 纯日期串解析：全站唯一点 Dashboard formatDate 已修（13#15），其余 Date.parse 输入均带 Z。
- 周几计算：week-dots 用后端本地日期串 + T00:00:00 本地解析正确；Plan 用 T12:00:00 防偏移。
- 倒计时：FocusLayer/ExamWorkspace 均绝对时间差 + setInterval 只触发重算（无漂移）；后端 resume 重写 startedAt 同式；考试截断方向安全（前端先归零）。
- 百分比 0-1/0-100 无混用；成本 $ 前缀 + 分层精度合理（6/8/2/1 位）；分钟→小时全站 /60 + toFixed(1) 一致。
- formatDate 三态兜底（纯日期/带时间/解析失败原样返回）不会显示 Invalid Date。
- 重复实现行为比对：本地日期串生成三处等价、mm:ss 两处同构、小时/百分比一致——无行为分歧的实现对。
