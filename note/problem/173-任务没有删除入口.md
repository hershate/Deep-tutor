# 173：任务没有删除入口

## 现象与触发条件

用户创建错误任务或需要清理已完成任务时，今日与学习计划的现有任务操作只有完成、专注和排期。首页提示“可在学习计划中清理已完成任务”，但计划页没有删除操作。

## 传递链条

1. `desktop/src/pages/Plan.tsx:176-178` 打开任务排期弹窗。
2. `:215-216` 只提供日期保存与完成状态切换；没有删除动作。
3. `desktop/src/pages/Dashboard.tsx:48` 将学习计划描述为清理已完成任务的位置，形成不可达指引。
4. 后端 `Store::replace_collection` 的 tasks 路径已支持删除，并同步清理专注关联与方案排期（`store.rs:946-953`）；缺陷在前端操作入口，不需要新命令。

## 影响范围

影响误建任务与历史任务管理。未排任务、已排任务、已完成任务均无法通过界面删除，集合与通知数据会长期累积。其他集合的删除功能不受影响。

## 修复验收

任务弹窗提供需确认的删除动作，调用真实 `replace_collection('tasks')` 并等待成功回执；删除后关闭弹窗并刷新计划。关联排期由后端事务清理，失败不显示成功。
