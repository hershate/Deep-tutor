### 62#4（=D-4）五处数字输入可输小数——后端整型反序列化失败并弹英文技术错误

  - `PlanGenerator.tsx:305` 每日分钟 → `daily_minutes: u32`

### 62#7（=D-7）「批量导入」按钮打开的是单文件选择器

- 位置：`Library.tsx:282`（按钮文案）↔ `backend/notes.ts:8-11`（`multiple: false`，仅 zip/md/txt）。
- 链条：① 用户点「批量导入」预期多选若干 .md → ② 对话框 multiple:false 一次仅可选一个文件 → ③ 真正的批量途径（预先打成 ZIP ≤1000 条）UI 无任何提示——对照同页「导入资料」是 multiple:true，预期落差被放大。
- 影响范围：批量迁移笔记的用户（换机/整理场景）：逐个导入或困惑后放弃；无数据风险。修复二选一：对话框改 multiple + 前端循环导入，或按钮文案改「导入笔记（ZIP/单文件）」。

### 62#8（=D-8）数据目录未创建时「在资源管理器中显示」直败——裸插件英文错误、无自救指引

- 位置：`DataDirectoryPanel.tsx:80-84`（catch → backendErrorMessage 原样上屏）、`:91`（按钮在 `ready===false` 时仍渲染）。
- 链条：① 初始化失败 → dataRoot 指向不存在的目录 → ② 用户点「在资源管理器中显示」→ ③ opener reveal 返回**非 BackendError 的原生字符串**（ShellExecute 失败描述，英文/系统级）→ ④ `String(error)` 分支原样上屏，面板底部一行红字——无「目录尚未创建，请先重试初始化」关联指引（重试按钮在更下方未被提示关联）。
- 影响范围：初始化失败用户（含 App 启动失败兜底页——该页同样内嵌此面板，恰是目录不存在概率最高的场景）；最需要引导的群体拿到一句无法理解的英文错误。修复：ready===false 时禁用按钮或 catch 中给出中文指引。

### 62#11（=D-11）配额上限越界仅静默禁用保存钮，页面无「1–100000」范围说明

- 位置：`SecurityPanel.tsx:128`。
