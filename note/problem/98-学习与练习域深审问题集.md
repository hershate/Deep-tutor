### 98#1 模拟考试（deferred 反馈）进行中，错题本与错题导出实时泄露正确答案解析

- 位置：`desktop/src-tauri/src/backend/practice/mod.rs:1211-1215`（客观题提交即写错题：`if !correct && set.feedback_mode != "hints"`——deferred 通过此检查，reason 为完整解析）、`:559-565`（考试模式强制 feedback_mode='deferred'：「模拟考试必须在交卷后统一反馈」）；`:1309`（mistakes() 查询 `FROM practice_mistakes m JOIN practice_questions q JOIN practice_sets s … LIMIT 500` 无任何 `s.mode='exam' AND s.status='completed'` 过滤）；导出走同一查询 `practice/commands.rs:81-91`；主观题评分完成同样写入（subjective.rs:475-479，reason=overall_feedback）；对照同域 detail() 明确遮蔽未完成考试（mod.rs:1065 `if set.status == "completed" || set.feedback_mode == "immediate"`）。
- 传递链条：①学生开考（deferred 强制）→ ②逐题 submit，答错即落错题行，reason 含完整解析（正确答案说明） → ③考试中途打开错题本（list_practice_mistakes 无守卫）或导出 JSON（export_practice_mistakes_file 同源） → ④看到刚答错题目的解析与参考信息，考试结果失真。未作答题不写错题（exams.rs:147-155，03#13-27），但已答错题在交卷前就进入错题本。
- 影响范围：考试完整性破坏——「交卷后统一反馈」的产品承诺被错题本与导出旁路；与 B-11/23#2（hints 遮蔽旁路，已修）同族，exam+deferred 组合未被守卫覆盖。
- 修复方向：考试内错题延迟到 exams::finalize 才写入（考试期间暂存），或 mistakes()/export 过滤 `s.mode='exam' AND s.status != 'completed'` 的集合。

### 98#2 题目生成无跨集合去重、无采样种子——高度复现历史题干，错题按行去重口径放大重复

- 位置：`desktop/src-tauri/src/backend/practice/mod.rs:796-816`（去重仅集合内 `seen.insert(question.prompt.trim())`；变式仅比对原题 prompt trim 相等）、`:887-890`（插入前无对 practice_questions 历史的查询）、`:376-436`（generation_prompt 无 seed/随机化注入；backend\random.rs 在 practice 域零引用）。
- 传递链条：①同一 node/stage 反复生成针对性练习，提示词几乎相同且无种子 → ②模型高度复现历史题干，集合内 trim 完全相等才拦截（内部空白差异即判不同） → ③重复题再次答错 → 新错题行？否——按 question_id 去重（ON CONFLICT 更新计数），但跨集合的同题干算两道独立题 → 各自进错题本 → 错题计数虚高、变式循环空转。
