第三轮安全实现审查（DEEPTUTOR 敏感路径）、迁移升级、测试/CI/构建、文档与仓库
一致性审计发现。验证通过未列入的面：web SSRF 防护链主体（DNS 锁定/逐跳校验/
凭据拒绝/UTF-8/1MB/测试例外防进生产）、ZIP 炸弹数值与声明一致、备份排除表
（secure_delete+VACUUM）、密钥不入日志/事件/CSV/备份、plugins 纯声明结构、

## 安全实现

### 1. IPv6 保留段排除条件为死代码，3fff::/20 与 3ffe::/16 类地址未被拦截
- 证据：`providers/openai.rs:139`——`!(segments[0] & 0xfff0 == 0x3fff)`：`x & 0xfff0` 低 4 位恒 0，永不等于 0x3fff（低 4 位为 f），分支永不生效；该函数被 `web/mod.rs:122` 与 providers 端点校验共用。
- 影响：`public_address` 放行新文档段 3fff::/20（RFC 9637）与旧 6bone 段；实际可利用性接近零（段地址不可路由），属防护意图未执行。[原意是 0x3ff0 还是 ==0x3fff 待作者确认]

### 2. 全部导出/导入命令接受 WebView 任意路径且静默覆盖既有文件
- 证据：`materials/commands.rs:76-92`（export 目的地任意）、`export/commands.rs:8-26`、`sharing/commands.rs:47-53`、`backup/commands.rs:21-34`、`reports/commands.rs:92-101`；`materials/mod.rs:1191-1213` 对任意 parent create_dir_all、对已存在目标先备份再替换（静默覆盖）；读侧 import 同样任意路径。
- 影响：正常 UI（系统对话框有覆盖确认）无损害；但后端命令层不提供第二道路径遏制——配合 06#4 无 CSP，注入脚本即得"任意内容写任意路径+任意文件读（受扩展名/大小/签名约束）"原语。属单层防御缺口。

### 3. 离线分享包校验仅完整性无真实性：任何人可伪造永不过期的合法 .dtshare
- 证据：`sharing/mod.rs:489-500`——checksum 为普通 SHA-256（无 MAC/签名），伪造者可自算；`:195-209` token 只验格式不查库；`:501-503` 过期校验用包内自声明值；`read_shared_plan_package/file` 在认证白名单内（guard.rs:158-163）。
- 影响：可构造内容任意的"分享方案"诱导用户打开；README"分享可撤销可过期"对离线包不成立（React 转义使内容注入不升级为 XSS，无 dangerouslySetInnerHTML）。

### 4. API Key/同步凭据/PAT 的输入路径未用 Zeroizing，明文驻留堆内存
- 证据：`providers/mod.rs:57/441/501-510`（ProfileInput.api_key 普通 String + clone）、`sync/mod.rs:99-101/359-379`、`security/mod.rs:1131-1140`（PAT 参数）；对比读取侧与 JWT 均正确使用 Zeroizing。
- 影响：密钥在 IPC 反序列化/校验克隆后堆中残留，进程内存转储可提取；可利用前提是本机内存读取权限（已越过全部应用边界），属纵深加固缺口。

### 5. 文档宣称 JWT"常量时间比对"，实现为短路逐字节比较
- 证据：`docs/architecture/01-architecture.md:177` vs `security/mod.rs:582-587`——`all(|(l,r)| *l == *r)` 首异即短路，另有长度早退。
- 影响：违反 DEEPTUTOR"不得宣称无强制实现的安全属性"；实际可利用性可忽略（比较对象是 HMAC 结果、经本地 IPC 测时）。

### 6. agent 免审批工具构成"读取本地数据→公网外发"链路，未在文档/UI 披露
- 证据：审批仅覆盖 memory.save/delete 与 artifact.promote（`agent/tools.rs:554-630`）；`web.search/web.fetch/history.search（跨全部会话）/memory.recall/workspace.read` 免审批；工具结果原文进入模型上下文（`agent/mod.rs:851-873`），web.fetch 抓回内容构成提示注入载体。
- 影响：被污染网页或恶意模型可在无用户确认下读本地学习数据再经 web.fetch 编码进 URL 外发任意公网地址；SSRF 链只拦私网目标不拦数据外发。与 02 文档 §313 记载一致（设计如此），但外发边界未披露。

### 7. Agent 双层预算完全依赖供应商上报 usage，缺 usage 时形同虚设
- 证据：token 预算按 `json_extract(usage_json,...)` 求和（`agent/mod.rs:608-615/787-791`，NULL→0）；USD 的 known_spend 要求 input+output 同时存在（`providers/usage.rs:261`）。
- 影响：不上报 usage 的兼容服务下真实计费不被任何预算拦截，仅受 25 步硬顶；与 02#8（直连旁路）不同根因。

## 迁移与升级

### 8. 一次性复制后根库旧业务表永久死重，materials 迁移还会在根库再生成一份死数据
- 证据：`store.rs:120-126` 复制后无清理；`store.rs:173` 对根库同样执行 `materials::migrate`，其 kv→materials 一次性导入（`materials/mod.rs:210-232`）在根库再跑一遍。
- 影响：旧库迁移用户业务数据在根库永久双份；无功能损坏。

### 9. 备份导入表清单强等校验使"缺表豁免"成死代码：下一次 TABLES 增量将拒收全部存量 .dtbackup
- 证据：`backup/archive.rs:529-543`——manifest.tables 键集合必须与当前 TABLES（67 张）严格相等，先于一切校验；`:596-608` 的豁免清单（允许缺 9 表）被前置强等拦截永不达；`transfer.rs:104-113` 逐表列集比较仅 focus_sessions.paused_at 一条例外。
- 影响：当前 1.0.0–1.0.5 schema 零变化无现实受害；下一张新表发布日起，之前全部 .dtbackup 无法恢复，报错文案指向"损坏"而非版本。

## 测试、CI 与构建

### 10. 39/189 个注册命令零 IPC 层测试覆盖，4 个全层零覆盖
- 证据：39 个命令在全部测试语料中无 IPC 调用（含 8 个 cancel_* 命令族、save_draft/get_draft/delete_draft、get_community_overview、list_plugin_events 等）；全层零覆盖 4 个：`import_provider_deep_link`（解析代码本身零测试）、`delete_provider_profile`、`logout_local_user`、`restart_application`。薄域：community 12 命令/2 测试、reports 11/2、review 9/2、engagement 8/2、plugins 8/2。
- 影响：note/14 验收要求 1/3（命令真实读写、取消恢复）存在实质空洞；多数底层函数有测但 IPC 参数映射层无回归保护。

### 11. CI 无 Rust 缓存 + 30 分钟超时 + 前端双重构建
- 证据：`ci.yml:24-28` 仅 npm cache；`:18` timeout 30 分钟；`:33` 显式 `npm run build` 后 `:41` tauri build 的 beforeBuildCommand 再全量构建一次；`:10-12` cancel-in-progress 掐长跑。
- 影响：冷缓存全量 release 编译+测试接近超时上限时 CI 红而本地绿[待确认]。

### 12. 工具链无钉住：CI 滚动 stable vs 本地 1.95
- 证据：`ci.yml:29` dtolnay/rust-toolchain@stable；无 rust-toolchain.toml；package.json 无 engines。
- 影响：fmt 规则随 stable 变化时出现"本地过 CI 不过"的不可复现差异。

### 13. pre-push 钩子无执行位，类 Unix 检出下静默跳过
- 证据：`git ls-files -s .githooks/pre-push` = 100644（应 100755）。
- 影响：Windows 无影响；Linux/macOS 执行 make hooks 后钩子仍被 git 跳过。

### 14. 前端零自动化测试、零静态检查门禁
- 证据：package.json 无 test 脚本与测试框架；无 ESLint；`tsconfig.json:17-18` 关闭 noUnusedLocals/Parameters；Makefile lint 不含前端专用检查。
- 影响：hooks 依赖错误（如 01#10 Modal P1）、死前缀监听等均为 exhaustive-deps 可捕获类；页面层回归完全靠人工。

### 15. 版本三处同步无自动校验；make build 不经 --locked
- 证据：`tauri.mjs:24-28` 仅用 tauri.conf.json 版本；Makefile/ci 无交叉校验；`Makefile:19` build 无 --locked（唯一 --locked 在 test 与 CI）。
- 影响：升版漏改任一处静默通过全部门禁；lock 失配时本地 build 静默改写 Cargo.lock。

### 16. sync 测试全局 DEFER 标志缺 RAII 复位；串行理由未在命令现场注明
- 证据：`sync/mod.rs:31` DEFER 进程级全局，`:848-853` 直改无 Drop guard（对比 web 的 SearchEndpointGuard）；`Makefile:26`/`ci.yml:39` 的 --test-threads=1 无注释。
- 影响：裸跑 cargo test（默认并行）时 sync 测试互相污染；defer(true) 后 panic 泄漏标志连带后续测试失败。

## 文档、许可与仓库一致性

### 17. NOTICE 要求分发保留"适用的许可全文"，但打包流水线无依赖许可落地机制
- 证据：`NOTICE:3/23`——仅指向 Cargo.lock（不含许可文本）；tauri.conf 无 license 字段；Makefile build 无许可汇编步骤；仓库仅两份全文（Apache-2.0/MIT）。
- 影响：安装包含数百个依赖的二进制，按 MIT 第 1 条分发需附版权与许可声明；已发布 6 个版本的安装包处于合规缺口。

### 18. DEEPTUTOR 敏感路径清单遗漏 export/ 与 commands.rs
- 证据：`DEEPTUTOR.md:66-76` 清单不含 export（生成 PDF/Anki/文件写磁盘，与 backup/sharing 同属文件输出域，且 :34/:78-82 明确要求密钥不入导出）与 commands.rs（全部 IPC 面）。
- 影响：清单自称"显式声明、不从文件名推断"，遗漏即等于宣告无需安全复审；后续改动可能绕过双审。

### 19. 仓库治理残留与缺口（合并条目）
- 旧运行数据残留：`backend/data`（含 sessions/evil、deep-tutor.db）、`data/`（含 .jwt_secret、日志、9 个插件目录）、`backend/.pytest_cache`——均未跟踪/已忽略，无入库违规，但为敏感本机残留且 README"已删除"口径仅对代码成立。
- `.git/dt_tools` 本地残留 62 个迁移期脚本与旧 Go 源副本（2.6MB）[待确认是否有意保留]。
- `docs/architecture`（4 个已跟踪文件）未列入 README 目录树，不在任何文档索引（"暗文档"）；`desktop/DESIGN.md` 是零引用孤儿规范。
- 1.0.0–1.0.5 六个已发布版本均无 git tag，无 note/release/ 目录（全局规约要求按版本 tag 与 release 说明）。
- 仓库根 TEMP/ 目录与 AGENTS"临时文件使用 F:\TEMP\deeptutor"并存且未入 .gitignore。
- `docs/architecture/03-workflow.md:30` 仍写"1.0.0→1.0.4 五个安装包；均为 1.0.4"（实际 1.0.5 六个）。
