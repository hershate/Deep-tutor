# 178：客观题已保存作答恢复后不回显

## 证据

- `desktop/src-tauri/src/backend/practice/mod.rs:1246-1295` 详情接口按反馈模式返回作答 `response`； deferred 进行期也保留考生本人原文。
- `desktop/src/pages/Practice.tsx:126-129` 切换练习集时清空 `selected` 与 `textAnswer`。
- `desktop/src/pages/Practice.tsx:259-268` 选项选中态和填空值只读这两个本地草稿，没有回退到 `answer.response`；错误选项判断也只看 `selected`。
- `desktop/src/components/ExamWorkspace.tsx:50,214,218` 已采用 `answer.response` 回退，说明同一数据契约在考试组件中已有正确实现。

## 完整传递链条

用户提交选择/填空答案 → 后端持久化 `response_json` → 用户切换练习集、离开页面或刷新详情 → 后端再次返回 `answer.response` → 前端清空本地草稿并仅以草稿渲染 → 已禁用选项没有本人选中标记，填空框为空， deferred 模式也无法确认保存内容 → 用户误以为答案丢失。

## 影响范围

- 针对练习的选择题与填空题。
- immediate、deferred、hints 三种模式下切换历史和刷新后的作答可见性。
- 不影响数据库中的原始答案；影响用户核对、继续完成整组练习及对保存状态的判断。

## 修复验收

- 选择题以本地未提交选择优先、已保存 `answer.response` 为回退；填空题在已作答时显示保存原文。
- 正误高复用同一回退值； deferred 进行期不得因此显示分数、标准答案或解析。
- 与考试组件的回退口径一致，前端构建通过。
