# 167：Agent 已有会话时无法选择新会话方案

## 现象与触发条件

Agent 工作台存在任一当前会话。左侧新建按钮会创建会话，但绑定方案的下拉框只在 `!activeSession` 时显示。

## 传递链条

1. `desktop/src/pages/AgentCenter.tsx:48` 保存 `newPlan`。
2. 同文件 `:106-109` 的 `create` 已能将 `newPlan` 传给 `createSession`。
3. `:122` 的加号按钮与 `:127` 的创建按钮都调用 `create`。
4. `:127` 同时用 `!activeSession` 隐藏方案下拉框；只要存在当前会话，用户不能把新会话切换到某个已采用方案。
5. `desktop/src/backend/useAgent.ts:197-208` 将省略的方案映射为 null，因此加号只能继续创建通用会话；后端绑定能力本身可用。

## 影响范围

影响 Agent 工作台的新建方案会话入口。已有通用会话后无法在本页改用方案上下文；已有方案会话后无法通过下拉框选择另一个方案。通用问答不受影响，后端已采用方案校验不受影响。

## 修复验收

无论是否存在当前会话，都能选择通用问答或任一已采用方案后新建会话；创建结果保持所选 `planId`，不改变现有会话。
