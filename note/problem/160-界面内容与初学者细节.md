# 160 · 界面内容与初学者细节

## 160#1 笔记公式按钮生成多余定界符

- 严重度：P2。
- 传递链：`Library` 的公式按钮调用 `insertAtSelection('\n$$P(A|B)=…$$', '$$\n')`；前缀已经包含完整的起始与结束 `$$`，后缀又追加一个结束标记，预览因此包含多余 `$$`。
- 影响范围：笔记编辑器、Markdown/KaTeX 预览与导出的笔记正文；零基础用户通过工具栏插入的第一个公式即带有格式错误。

## 160#2 新笔记被默认标记为“概率论”

- 严重度：P2。
- 传递链：`Library` 将 `noteTag` 初始值及无草稿打开时的回退值固定为“概率论”；新建任意学科笔记都会携带该标签，除非用户主动改正。
- 影响范围：笔记保存、标签过滤、全局搜索展示与导入导出；产生与用户内容无关的持久化分类。

## 160#3 通用布局仍允许长内容越界

- 严重度：P2。
- 传递链：全站 `.badge` 与 `.btn` 使用 `white-space: nowrap`；页面标题、错误条、任务中心等 flex 文本列缺少统一的 `min-width: 0` 或折行规则；`.modal-body` 没有通用长串折行；讲义 Markdown 的 `pre` 没有横向滚动规则，而外层 `.reading-article` 使用 `overflow-x: clip`。用户标题、URL、哈希、模型输出或无空格正文可越过卡片、弹窗和窄窗口边界。
- 影响范围：全部页面与弹窗，重点包括动态 Badge/按钮、确认框中的记忆卡正文、Agent 任务标题、方案错误信息和讲义代码块。

## 160#4 考试填空输入缺少后端同限值约束

- 严重度：P3。
- 传递链：`ExamWorkspace` 的填空输入直接保存任意长度的 `event.target.value`，同文件主观题及针对练习均使用 30000 字节钳制；提交后由练习后端统一校验响应大小。
- 影响范围：模拟考试填空作答；长文本只在提交时失败，且输入侧没有可预判的边界。

## 160#5 社区侧栏预约绕过在途防重

- 严重度：P3。
- 传递链：主列表的预约按钮受 `busy` 禁用，右侧“下一场安排”的同一 `reserve()` 入口没有 `busy` 禁用；`reserve` 自身虽检查 busy，但第二次点击会被静默忽略。
- 影响范围：社区侧栏预约/取消；连续点击时第二次操作无状态反馈，与主列表行为不一致。
