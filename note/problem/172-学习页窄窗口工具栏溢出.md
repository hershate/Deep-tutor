# 172：学习页窄窗口工具栏溢出

## 现象与触发条件

学习页在应用允许的 375px 最小窗口宽度下，阅读标签与右侧四个图标操作保持单行，横向超出内容区。

## 传递链条

1. `desktop/src/pages/StudyRoom.tsx:292` 的 `.reading-toolbar` 同时包含三个内容标签、字号减/增、讲义生成和笔记按钮。
2. `desktop/src/styles.css:462-467` 将 toolbar 设为不换行 flex，标签不换行；四个 `.icon-btn` 均为 44px 固定宽度（`:163`）。
3. 仅按钮固定宽度已为 176px，再加三个含文字标签、间距与水平 padding 后超过 375px 内容宽度。
4. 当前没有窄窗口换行或容器内横向滚动规则，内容进入相邻区域或超出窗口。

## 影响范围

影响学习空间最小宽度与大字体设置下的讲义、笔记和字号操作；不影响后端命令。长期动态文本换行规则不能修复这个固定控件宽度累加问题。

## 修复验收

375px 下工具栏在自身容器内换行，所有操作仍可见、可点击；宽窗口维持单行。不得用隐藏操作代替修复。
