## P3

### 96#1 登录签发中途失败 + login() 预先清除 logged_out 标记 → 机器静默回退为管理员自动会话

- 位置：`desktop/src-tauri/src/backend/security/mod.rs:959-964`（login 第一件事 `state.logged_out.store(false)` 后才调 `issue()`）；`:651-675`（issue 先撤销**全部**活跃会话并提交，之后才进行 JWT 生成与 keyring 写入——任一失败即返回 Err）；`:753-764`（initialize 在 `login_required` 且 `logged_out == false` 时不拦截，自动以第一个 active 管理员签发新会话）；guard.rs:200-209（switch 失败回滚仅还原 store 与后台，不动会话状态）。
- 传递链条：①用户调用 `login_local_user` 以**成员**身份登录：logged_out 先被置 false → ②issue() 段内撤销全部现有会话（含现任管理员的）已提交，随后 `secret()`/`credentials.set()`（keyring 读写）失败 → 返回 Err，此刻库内零活跃会话且 logged_out=false → ③下一条任意命令进入 `current() → initialize()`：命中 login_required 但 logged_out=false，不拦截 → 自动以第一个管理员身份签发新会话 → ④机器从「尝试登录成员失败」静默落到管理员身份，违背用户的显式选择；与 23#6/31#7 注释声明的「登出撤销不被下一条命令抵消」语义冲突。
- 影响范围：触发条件为 issue 中途 keyring/时间原语故障（概率低）；本地应用无口令（login 本就不校验凭证，AuthMode 声明「本地身份选择不代替 Windows 账户认证」），故非严格意义的越权突破，但管理员面板（建用户/改配额/撤令牌）在用户选择成员后被静默启用，「用户显式登出后不再自动以管理员身份重登」的撤销防线（23#6/31#7）在该路径被绕过，语义错误明确。
- 修复方向：issue() 改为「先建新会话记录并提交，成功后再撤旧」（或撤销与新会话同一事务）；或 issue 失败路径恢复 logged_out 原值；或 initialize 的自动管理员登录仅限「库中从未存在任何会话」的首次启动场景。

### 96#2 user1 一次性库复制与常驻账户连接存在撕裂窗口

- 位置：`desktop/src-tauri/src/backend/store.rs:187-203`（checkpoint 后 drop 连接，随后 `fs::copy(&root, &staged)` 复制主库文件——staged→rename 原子性只保证目标路径完整，防不了**源文件**复制中途被并发改写）；并发写者：SecurityState 惰性创建后长存的账户连接（security/mod.rs:314-323）此刻仍可提交，WAL 下任何自动 checkpoint（默认 1000 页阈值）会改写主文件本身。
- 传递链条：①升级后首次以 user1 打开工作区（`!path.exists()` 路径） → ②fs::copy 读取主文件中途，账户库恰好发生自动 checkpoint 改写同页 → ③拷贝出的 `users/1/<db>` 为页级新旧混合的撕裂库，后续打开报 disk image malformed。
- 影响范围：账户库写入量小、1000 页窗口内触发概率极低；一旦发生 user1 工作区不可用。
- 修复方向：复制期间对源库取短 `BEGIN IMMEDIATE`（阻塞其他写者），或 checkpoint 后以只读事务持快照再复制。

### 96#3 媒体 verify 后置校验只挡播放不挡字节投递；硬链接绕过目录围栏

- 位置：`desktop/src-tauri/src/backend/materials/media.rs:95-98`（只检测符号链接——硬链接使 canonicalize 解析为自身、`starts_with(canonical_root)` 通过）、`:186-190`（chunk_bytes 直接读无哈希）；前端 `desktop/src/components/MediaPlayer.tsx:29-36`（字节先入 parts 数组，`verify()` 在传输**全部完成后**才调用）。
- 传递链条：①info() 全量流式哈希通过 → ②对数据目录有写权限的本地进程在 info 与 chunk 之间把原件替换为指向受害文件的硬链接 → ③chunk 逐块把受害文件字节送入 WebView（已进入内存），verify 不匹配只阻止播放器创建——投递层未闭合（播放层已闭合，46#2）。
- 影响范围：前提是攻击者已可写应用数据目录——该前提下本可直接读受害文件，**未突破实际信任边界**；如实记录为 46#2 声明的 TOCTOU 关闭在投递层不完全。
- 修复方向：chunk 读取维护增量哈希、末块与 `material.sha256` 比对后再放行（成本与现有 verify 相同但前置）；或打开后 fstat 比较 inode/size 与检查时一致。

### 96#4 分享包 2MB 上限只量 snapshot，不含 package 外层字段——边界处「创建成功但永远读不回」

- 位置：`desktop/src-tauri/src/backend/sharing/mod.rs:296-302`（create 只检查快照 payload 长度 ≤ MAX_PACKAGE_BYTES）、`:508-513`（read_package 检查整个包串 ≤ 同一上限）；`make_package`（:351-367）在快照之外还嵌入 token（46 字节）、checksum（64 字节）、expires_at 与字段名/引号 ≈ 合计 +250 字节。
- 传递链条：①极大快照（长度落在 2MB−250 至 2MB 区间）通过 create 校验 → ②前端把 package 交给 read 或导出 .dtshare 后再读 → ③被整包长度检查拒绝——用户拿到令牌与包却无法读取/导出，不可自愈。
- 影响范围：约 250 字节的边界窗口，触发概率低。
- 修复方向：create 对 make_package 产出的最终串长度校验（或快照上限收紧 MAX_PACKAGE_BYTES − 512）。

### 96#5 插件卸载「先删目录后删 DB 行」的反向窗口

- 位置：`desktop/src-tauri/src/backend/plugins/mod.rs:679-695`（`fs::remove_dir_all(directory)?` 在 `DELETE FROM plugins` 事务之前；14#16 注释只论证了「目录删除失败保持两边一致」方向）。
- 传递链条：①并发 IPC/长事务占库时卸载 → ②目录删成功、随后的 DELETE/commit 因 busy_timeout 失败 → ③磁盘清单已消失而 DB 行（enabled=1）残留：dispatch（:713-727）仍按 enabled 行投递事件、reload 永远 `plugin_manifest_missing`，用户重试卸载才可收尾。
- 影响范围：概率低的一致性窗口（无代码执行面、无数据外泄，可重试恢复）。
- 修复方向：卸载先 `UPDATE plugins SET enabled=0`（独立小事务）再删目录最后 DELETE；或 DELETE 失败路径补删并返回可重试专用错误码。

### 96#6 Anki 导出 sfld 字段未滤控制字符，与 flds 口径不一致

- 位置：`desktop/src-tauri/src/backend/export/anki.rs:192-194`（`params![…, format!("{}\u{1f}{}", field(&card.front), field(&card.back)), card.front, …]`——flds 走 `field()` 滤控制符（31#26），sfld 直接用原始 front）。
- 传递链条：①卡正面含 \u{1F} 等控制符 → ②flds 已滤、sfld 保留 → ③Anki 依赖 sfld≈首字段做排序/查重时两边不对齐（不破坏 \x1f 字段边界，导入不失败）。
- 影响范围：极低——仅显示级不一致。
- 修复方向：sfld 用与 flds 同源的过滤副本。

## 核实通过项（免后续复查）

- JWT：deny_unknown_fields + alg 固定 HS256（alg=none/混淆不可行，mod.rs:529-534/598-600）；常量时间签名比较（08#5）；exp 无 leeway（单机同钟）且 DB expires_at 字符串等值锚定（合法签名也无法自定 exp/sid）；无续期机制，7 天固定属设计口径。
- PAT：32 字节 CSPRNG（`dtp_`+43 字符）；库内仅存无盐 SHA-256（256-bit 随机值无字典面）；吊销/删除语义正确（21#1/31#7/31#34）；revoke PAT 不追杀已发 JWT 属标准语义。
- 登录无限速：本地用户无口令（login 不校验凭证），无暴力破解面，属声明边界非缺陷。
- 会话并发：全局单会话 + WORKSPACE_SWITCH 写锁串行；锁序无嵌套（34#2）；73#1 owner 镜像不损语义；一窗登出全线失效。
- 事件 outbox：id AUTOINCREMENT 严格单调（裁剪后不复用）；裁剪双条件（90 天 AND 保底 2 万条）与唯一 SQL 重放消费方不冲突；Last-Event-ID 负游标拒绝、has_more 按原始行数（81#5）。
- schema 指纹：按 type/name/tbl_name 排序后哈希，对 DDL 顺序不敏感；VACUUM/文件复制后稳定；降级门 user_version 与 meta 双取最大（46#3）。
- user1 迁移幂等：`!path.exists()` 守卫 + staged 原子改名，二次登录跳过；materials 一次性导入双守卫。
- revision：读-改-写在事务内、单写者下严格单调；溢出显式报错（86#8）；kv replace 全量原子（同一 IMMEDIATE 事务）。
- media 分块边界：offset/length 校验、短读截断、EOF 信号、并发独立 File::open 无共享偏移；MIME 按魔数（ftyp/EBMK/RIFF/PNG/JPEG/GIF）导入即校验，伪装文件在导入被拒。
- random.rs：Windows BCryptGenRandom / Unix /dev/urandom 均 OS CSPRNG，故障显式报错；会话 id/JWT 密钥/PAT/分享令牌复用同一入口但各自独立抽 32 字节；全库无 StdRng/uuid/时间戳拼接。
- plugins 沙箱：清单 deny_unknown_fields 纯声明式、200KB 上限；asset 全内存 include_str! 不触盘；事件订阅白名单 14 命名空间（61#1）；事件视图只暴露 kind 不暴露 payload。
- sharing：令牌 256-bit 熵、库内只存 sha256；checksum 覆盖全部载荷；过期全程绝对时间比较与时区无关；导出强制 .dtshare 扩展 + reject_data_root_destination + 原子写；撤销不追溯已导出离线包为设计语义（tests.rs:225-267 固化），建议 UI 文案明示。
