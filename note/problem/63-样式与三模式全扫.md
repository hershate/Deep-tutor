### 63#2（=H-2）Agent 工作台用户气泡深色漏网——亮绿底白字对比约 1.3:1

- 位置：`styles.css:1155`（`.agent-user .agent-bubble` 的 `background: var(--accent-strong); color: var(--paper-50)` 组合无 dark 覆盖）。
- 传递链条：① 用户切深色主题 → ② 变量翻转：accent-strong 变亮绿（L≈0.87）、paper-50 仍近白（L≈0.985）→ ③ 该组合本需深色反色（同文件其余 5 处均加 `[data-theme="dark"]` 反色规则），此条漏网 → ④ Agent 对话中**用户自己发的每条消息**呈亮绿底白字，对比约 1.3:1。
- 影响范围：深色主题下的全部 Agent 工作台用户、每条用户消息必现——几乎不可读，只能靠消息布局（右对齐）辨认归属；浅色主题正常。48#2（Badge 抹平）同族最重漏网，一行补反色即修。

### 63#3（=H-3）导出回执警告文字硬编码深棕无深色覆盖

- 位置：`styles.css:1316`（`.export-receipt .export-warning { color: oklch(0.55 0.14 60) }` 不经变量）。
- 传递链条：① 导出中心产出带警告的回执（如 PDF 缺字形提示）→ ② 警告文字色为硬编码深棕 → ③ 深色主题下父容器 accent-soft 变深绿（L≈0.34），文字色不随变量翻转 → ④ 深棕字在深绿底上对比约 2.1:1（浅色下本就仅约 2.8:1）。
- 影响范围：深色主题下导出中心所有警告文字（缺字形/截断等质量提示）难以辨认——用户可能漏读质量回执继续使用有缺陷的导出产物。改走 `--warning` 类语义变量即可双主题修复。

- 传递链条：① 深色主题表面亮度 ≈0.245 → ② danger/success 保持浅色主题的中亮度值 → ③ 以纯文字消费这两色的六处声明对比仅 2.3-2.7:1（AA 要求 4.5:1）→ ④ 错误提示正文、错题选项标注等关键反馈文字在深色下辨识度不足。
