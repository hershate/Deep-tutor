### 146#1 侧栏关闭态键盘焦点泄漏（无 inert/visibility）

- 位置：`desktop/src/App.tsx:470`（`<aside className="sidebar …">` 常驻 DOM）+
  `desktop/src/styles.css:116-117`（`.sidebar { transform: translateX(-102%) }`、
  `.sidebar.is-open { transform: translateX(0) }`）；对照 styles.css:340（≥1024
  时 `.mobile-close, .mobile-menu, .mobile-bottom-nav { display:none !important }`
  正确摘除，关闭态侧栏无同等处理）。
- 传递链条：①<1024px 布局下侧栏抽屉关闭；②transform 仅视觉移出屏外，不将元素
  移出 Tab 序；③`.mobile-close`、全部 `.nav-group button`、`.sidebar-bottom
  button` 仍可被 Tab 聚焦——键盘用户从顶栏 Tab 会落入不可见按钮，focus-visible
  描边画在屏外，「焦点消失」；屏幕阅读器同理读到隐藏导航。违反 DESIGN.md:33
  「焦点圈禁（Tab 不穿出遮罩）」的自家承诺（弹层已实现、侧栏未实现）。
- 影响范围：受影响=窄窗口/移动布局下的键盘与读屏用户；不受影响=指针用户、
  ≥1024 常驻显示态。损害性质=可访问性断点。
- 修复方向：关闭态给 aside 加 `inert`（React 18 经 ref 设属性）或 CSS 关闭态
  `visibility:hidden` + `.is-open { visibility:visible }`（配 transform 过渡延后
  visibility 切换）。

### 146#3 学习热力图触控目标低于 WCAG 2.5.8 最小 24px

- 位置：`desktop/src/styles.css:1576-1578`（`.learning-heatmap { grid-auto-columns:
  minmax(10px,1fr); gap:5px }`、`button { min-width:12px; aspect-ratio:1 }`、
  `.learning-heatmap button { min-height:14px }`）。
- 传递链条：①84 天 ÷ 7 行 = 12 列；375px 视口下容器约 295px，扣 11×5px 间隙后
