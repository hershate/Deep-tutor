### 104#2 91#10 角标计数无法与真实任务对账——resume 不产生 started 事件使计数偏低提前归零，订阅重建窗口使计数残留偏高

- 传递链条 A（偏低）：①会话 A 的 run 运行中（计数 1）→ ②用户在另一会话恢复 failed run（run_resumed 不 +1；跨会话并行被 mod.rs:1216 的 per-session 检查允许）→ 实际 2 个在跑、计数仍 1 → ③恢复的 run 到终态 → `Math.max(0, 1-1)=0` → ④会话 A 仍在消耗预算但角标消失。链条 B（偏高）：①started 事件到达（+1）→ ②loginRequired 翻转订阅拆除，终态落在无监听窗口 → ③重新登录 effect 重跑但不重置 modelTasks → ④角标永挂「N 个模型任务进行中」，任务中心却找不到运行任务。
- 影响范围：全局问知舟角标可信度；91#10「抽屉关闭后任务运行可见」的目标在两种窗口下失效。
- 修复方向：+1 正则补 `run_resumed`；`ready`/`loginRequired` 变化重建订阅时向后端查询校准（或清零重计）。

### 104#9 专注恢复 loading 期「取消并重置」图标可点，确认后是空操作

### 104#10 91#1 边缘：非小写 `HTTPS://` 与协议相对 `//` 链接落入「该链接类型不支持」，文案失真
