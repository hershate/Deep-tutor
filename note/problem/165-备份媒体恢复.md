# 165 · 备份媒体恢复

## 165#1 备份导入白名单遗漏六种已支持原件

- 严重度：P2。
- 传递链：资料导入支持 M4A、PNG、JPG、JPEG、GIF、WebP，备份导出也会按数据库记录收集这些原件；`backup::transfer::target_relative` 的独立 `KNOWN_EXTENSIONS` 却不包含它们。导入时这些文件被改名为 `orphan-*`，而材料行仍保留原 kind，后续按 `{sha256}.{kind}` 定位失败。
- 影响范围：全量备份的跨目录/跨设备恢复、媒体预览、原件导出和缺失原件检查；备份本身可成功，但恢复后六类原件实际不可用。
- 结构原因：备份侧复制了一份扩展名列表，未复用 `materials::SUPPORTED`，新增媒体类型时两处发生漂移。
