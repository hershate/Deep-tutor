# 88 号：打包产物与依赖供应链问题集（第三十一轮·横切审计）

## P3

### 88#1 NOTICE 与 LICENSE-REASONIX 未随安装包分发，与自身声明不符

- 位置：仓库根 `NOTICE:3`（「分发本仓库或构建产物时，必须同时保留本文件及适用的许可全文」）↔ `desktop/src-tauri/tauri.conf.json:37-39`（bundle.resources 仅收 `licenses/*`）。
- 传递链条：①collect-licenses.mjs 只收集 Cargo/npm 依赖许可；②解包实测顶层仅 $PLUGINSDIR、deep-tutor-workspace.exe、licenses/、uninstall.exe——NOTICE、根 LICENSE、LICENSE-REASONIX 均不在包内，licenses/ 中亦无 reasonix 条目；③安装包作为唯一交付物单独流通时，上游 Reasonix（MIT）的版权与许可声明缺失，与 NOTICE 自设义务直接矛盾。
- 影响范围：分发合规缺口；与 84#1（README 许可表述错误）叠加后披露链混乱。
- 修复方向：collect-licenses.mjs 或 bundle.resources 一并收录 NOTICE / LICENSE / LICENSE-REASONIX 到包内。

### 88#2 38 个 Rust 依赖许可文本缺失，仅有「以上游仓库为准」的兜底声明

- 位置：包内 `licenses/COLLECTED.md`（「已收录 618 个依赖……另有 38 个 Rust 依赖在本地源码与 .crate 归档中均未找到许可文件，许可以 Cargo.lock 记录的上游仓库为准」）。
- 传递链条：①部分 crate 归档确实不含许可文件；②MIT/Apache-2.0 的分发义务要求随分发附许可文本；③38 个缺口构成批量合规缺口，且未列名单无法事后核验。
- 修复方向：collect-licenses.mjs 输出这 38 个包的名单与适用许可类型（可按 crate 元数据 license 字段推断），至少把名单写进 COLLECTED.md 供核验；有条件的从上游 tag 补齐文本。

### 88#3 根 README 直连构建命令缺 `-- -- --locked`，与自称「同一口径」不符

- 位置：`README.md:35-41`（直连路径 `npm run tauri build` 无参数，:35 却称「两条路径同一口径」）↔ Makefile build 目标与 desktop/README.md:35 均带 `-- -- --locked`。
- 传递链条：①按根 README 操作；②Cargo.lock 与 manifest 不匹配时静默更新锁文件而非失败；③可能带漂移依赖出包。
- 修复方向：根 README:40 补 `-- -- --locked`。

## 信息

### 88#4 WebView2 为在线下载引导模式，全新离线机器安装失败

- tauri.conf.json 未配置 `webviewInstallMode`（Tauri 2 默认 downloadBootstrapper）；解包 $PLUGINSDIR 无内嵌 MicrosoftEdgeWebview2Setup.exe。无网且未预装 WebView2 的机器安装失败。绝大多数 Win10/11 已带 Evergreen，实际影响面小；产品含本地学习场景，若需离线可改 `embedBootstrapper`（安装包增重）。

### 88#5 主程序 LegalCopyright 元数据为空

- 解包主程序 VersionInfo 的 LegalCopyright 为空；tauri.conf.json 未设 `bundle.copyright`。一行配置即可补上。

### 88#6 Cargo 传递依赖多版本冗余（非功能重复）

- Cargo.lock 中 base64 0.21.7/0.22.1/0.23.1 三版、bitflags 1.3.2/2.13.2、schemars 0.8.22/0.9.0/1.2.3、miniz_oxide 双三版共存。仅编译时间与体积影响，无功能冲突，不值得强行收敛。npm 侧 9 个生产依赖无重复。

### 88#7 lock 中 openssl 系列版本偏旧，但不进入 Windows 产物

- openssl 0.10.66 / openssl-sys 0.9.103（2024-08）在 lock 中，但 reqwest 走 native-tls，Windows 解析到 schannel，openssl 链仅其他 target 编译。本安装包不受影响；若未来出 Linux/macOS 版需复查（无已知未修复重大 CVE 记录，不确定，标注）。

### 88#8 关键 crate 供应链快照

- tauri 2.12.5 / wry 0.57.1 / reqwest 0.12.28 / rusqlite 0.38.0 / serde 1.0.229 / hyper 1.12.0 / idna 1.1.0：均无已知未修复重大 CVE（凭知识判断）。jsonwebtoken 不在依赖树。zip 2.6.1、lopdf 0.35、quick-xml 0.42 为 2025 年较新版本，历史 RUSTSEC 所涉版本均高于修复线（lopdf 旧告警情况不完全确定，标注）。vite 锁 5.4.21 ≥5.4.15 修复线（含 CVE-2025-30208/31125/32395/46565 全部修复）且仅构建期使用。
