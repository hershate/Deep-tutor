# 157 · 无资料学习闭环

## 157#1 资料被前端与后端同时强制为必选

- 严重度：P1。
- 传递链：`PlanGenerator` 以 `selected.length > 0` 计算 `ready`，同时禁用「继续澄清目标」和「开始生成方案」；`start()` 再以 `!ready` 拒绝提交；即使绕过界面，`learning::validate_input` 仍对空 `material_ids` 返回 `invalid_materials`。
- 影响范围：所有没有现成资料的首次使用者；纯目标驱动的方案生成完全不可达，与“辅助材料可选”的产品要求冲突。

## 157#2 只放开入口仍会在知识图谱步骤失败

- 严重度：P1。
- 传递链：空 `material_ids` 经 `pipeline::sources` 可得到空数组；`graph_prompt` 仍要求每个节点至少一条资料原文引用；`validate::validate_graph` 对空 `citations` 返回 `citation_missing`，空资料下任何引用又会命中 `citation_out_of_scope`。
- 影响范围：无资料方案的八步流水线、方案恢复、局部重生成；只修 157#1 会把入口错误后移为运行失败。

## 157#3 无资料方案的讲义生成仍强制引用

- 严重度：P1。
- 传递链：方案步骤 0 保存空快照后，`lecture::run` 将其传给 `unit`；讲义提示词仍要求“正文必须基于资料”且至少一条引用；`lecture::validate_content` 对空引用返回 `citation_missing`，Agent 讲义产物校验复用同一函数。
- 影响范围：学习空间逐单元讲义、恢复与新版本、Agent scratch 写入和产物提升。

## 157#4 无资料方案的练习与主观评分仍强制引用

- 严重度：P1。
- 传递链：`practice::sources` 可读取空快照，但 `GENERATION_SYSTEM`、`generation_prompt` 和 `validate_citations` 仍要求每题至少一条原文引用；主观题 `grade` 在评分前校验题目引用，评分后又用同一函数校验模型反馈引用。
- 影响范围：针对练习、模拟考试、错题变式、主观题评分与恢复；无资料方案即使生成成功也无法进入完整练习闭环。

## 157#5 页面说明把可选资料写成前提

- 严重度：P2。
- 传递链：方案空态、学习空间、知识地图、练习、主观题和考试分别显示“通过真实资料”“包含资料的学习方案”等固定前提；这些文案又反向强化 157#1 的入口限制。
- 影响范围：首次使用引导与所有无资料方案页面；即使后端打通，用户仍会误以为必须上传材料。
