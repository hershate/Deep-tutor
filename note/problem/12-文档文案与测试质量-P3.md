- 传递链条：触发（开发者/CI 执行 agent 与 learning 的取消语义测试，且机器高负载）→ 根因（agent/tests.rs:747 服务端 `sleep(300ms)`、learning/tests.rs:411 `sleep(500ms)`、:858 `sleep(400ms)` 由服务端线程承担"输出 delta→等待取消窗口"的时序）→ 传导（主线程须在窗口内轮询到 delta 并完成 cancel，余量约 10 倍，慢机越界即断言取消未生效）→ 症状（偶发假失败，报错方向指向"取消未生效"误导排障）。
- 影响范围：功能面：agent 与 learning 的取消语义测试；触发条件：CI/本机负载高导致时间窗错失时；受损面：假失败误导——非确定性失败浪费排查时间。
