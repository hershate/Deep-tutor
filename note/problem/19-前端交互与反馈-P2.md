## 19#1 复习页全局键盘劫持：全局搜索弹窗内无法输入空格，数字键在后台真实评分

- 位置：`desktop/src/pages/Review.tsx:64-73`；受害输入框 `desktop/src/App.tsx:420`（全局搜索弹层，`autoFocus`）
- 证据：
  ```ts
  // Review.tsx:66-69
  if (editorOpen || manageOpen || !card || busy) return
  if (event.code === 'Space') { event.preventDefault(); setFlipped(value => !value) }
  const keys: Record<string, ReviewGrade> = { Digit1: 'again', ... }
  if (flipped && keys[event.code]) { event.preventDefault(); void grade(keys[event.code]) }
  ```
  监听挂在 `window` 上，守卫只覆盖本页两个弹窗（editorOpen/manageOpen），不感知
  App 层全局弹层（⌘K 搜索、通知、快速记录）与导师抽屉。在复习页打开全局搜索后：
  空格被 `preventDefault` 吞掉（带空格的查询词无法输入）；若卡片处于翻面状态，
  键入 1–4 会对卡片**真实评分并写库**（`grade` 调用后端）。
- 影响：输入受阻 + 后台误操作写库；键盘可达性承诺（PRODUCT.md）在组合弹层下失效。
- 修复方向：handler 增加全局弹层状态守卫（App 层弹层打开时跳过），或检测
  `event.target` 是否可输入元素，或改为只在卡片聚焦时响应。

## 19#2 专注计时到 0 后完成失败 → 每秒重试 + 每秒错误 toast 的 1Hz 风暴

- 位置：`desktop/src/App.tsx:377-387`（tick）、`desktop/src/App.tsx:203-213`（finishFocus 失败路径）
- 证据：
  ```ts
  // App.tsx:380-382
  const remaining = Math.max(0, session.plannedSeconds - Math.floor((Date.now() - Date.parse(session.startedAt)) / 1000))
  if (remaining === 0 && !busy) void onFinish(false)   // 每秒触发
  ```
  `finishFocus` 失败时 `catch { reportBackendError(error); return null }`，不更新
  `focusSession`——session 仍为 running、`remaining` 恒为 0，下一秒再次调用
  `completeFocus`。后端 `no_active_focus`（`desktop/src-tauri/src/backend/reports/mod.rs:357,363`）
  不在 `isCancelRace` 名单（`desktop/src/backend/client.ts:424-441`），finishFocus
  也未做竞态过滤。
- 影响：一旦完成请求持久性失败（如并发完成、会话已被结束），每秒一次后端调用 +
  每秒一条错误 toast，直到用户手动退出专注层。
- 修复方向：完成失败时对 `no_active_focus` 做竞态判定（本地 session 作废），或
  连续失败 N 次后停止自动重试并提示手动处理。

## 19#4 复习保持率解释文案与后端算法相反（again 实际计 0 参与均值）

- 位置：文案 `desktop/src/pages/Review.tsx:133`；算法 `desktop/src-tauri/src/backend/review/mod.rs:505-508`
- 证据：
  ```ts
  // Review.tsx:133 —— 括号内声明"再来一次不计入均值"
  保持率按困难 60%、良好 80%、轻松 100% 的历史反馈均值计算（再来一次不计入均值）
  ```

  // review/mod.rs:505-507 —— 13#16 注释明说"again 显式计 0%"，参与 AVG
  // 13#16：again 显式计 0%，未知/异常档位不再被 ELSE 吞成 0 拉低均值

## 19#8 package-lock.json 根版本 1.0.5 落后于 package.json 1.1.0，check-versions 漏检此载体

- 位置：`desktop/package-lock.json:3,9`（`"version": "1.0.5"`）；`desktop/package.json:4`（`"version": "1.1.0"`）；校验脚本 `scripts/check-versions.mjs`（仅查 package.json/Cargo.toml/tauri.conf.json/README 四处）
- 证据：git 历史——package.json 于 `3c6b0242`（11-07，"版本 1.1.0"）升版，
  package-lock.json 最后一次变更停留在 1.0.5（`5851662d`，11-06），升版时未重新
  生成 lockfile。`NOTICE:23` 将 package-lock.json 列为依赖版本公示载体。
  `npm ci` 不校验根包版本，CI 与门禁均无法拦截。
- 影响：版本公示载体失真；依赖锁内根元数据与实际发布版本不一致。
- 修复方向：`npm install --package-lock-only` 重新生成；并将 package-lock.json
  根版本纳入 check-versions.mjs 检查范围。
