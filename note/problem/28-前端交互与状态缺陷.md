# 28 号 · 前端交互与状态缺陷（P1 × 1 + P2 × 2 + P3 × 8）

> 第十二轮对前两轮未深审的页面/组件逐行审计（StudyRoom、TutorPanel、Reports、考试工作区、
> 各设置面板）。核心条目均经主审回源码实证。

## P1

### 28#1 StudyRoom 首次生成/恢复生成讲义：事件刷新携带无效版本号 0，报错风暴后弹窗死锁整页

- 位置：`desktop/src/pages/StudyRoom.tsx:66-73`（`readingVersionRef.current = version ?? next.version`）、`:116`（`lecture.*` 事件 `refreshLecture(readingVersionRef.current)`）、`:234`（弹窗 `onClose={() => { if (!running) setLectureOpen(false) }}`）；后端 `learning/lecture.rs:214`（空讲义返回 `(0, "empty", …)`）、`:200-205`（`version=Some(0)` 查 `learning_lecture_versions` 无行 → `not_found "讲义历史版本不存在"`）
- 证据链（主审复核）：从未生成过讲义的阶段，首次 getLecture 返回 version=0 → ref=0；
  点"开始生成"后每条 `lecture.started/unit_started/unit_completed/completed` 事件都走
  `refreshLecture(0)` → 后端 not_found → 错误横幅反复出现、进度与直播输出永不更新；
  `lecture.completed` 同样报错 → lecture 永久停留 running → 弹窗关闭被 `running` 挡住，
  "取消生成"命中后端 `no_active_lecture`（flag 已随线程结束移除）被 isCancelRace 静默吞掉
  ——全屏 Modal overlay 锁死整页，只能重启应用。次级形态：已读 v1 再"生成新版本"时
  ref=1，事件把 UI 拉回 v1，新版进度与取消入口消失；"恢复生成"（failed 版本，versions
  表同样无行）同病。
- 修复方向：generate()/恢复前将 ref 重置为 undefined（跟当前），或后端对 version=0/生成中
  返回现状而非 not_found；弹窗 running 卡死加兜底关闭。

## P2

### 28#2 考试/主观题翻题时静默丢弃未保存答案（草稿与选中项）

- 位置：`desktop/src/components/ExamWorkspace.tsx:52`、`desktop/src/components/SubjectivePractice.tsx:45-48`
- 证据：`useEffect(() => { setSelected(null); setDraft('') }, [index])`——草稿只在组件
  state，点"下一题"即清空，无确认、无暂存、无恢复；论述题长文一次误点即丢。

### 28#3 考试倒计时归零后无任何自动动作，UI 停留在"剩余 00:00 但仍可作答"的矛盾态

- 位置：`desktop/src/components/ExamWorkspace.tsx:53-60`（计时 effect 只 setSeconds）、`:142`（过期禁用全靠 detail 拉取时后端计算的 `examExpired`）
- 证据：到点后输入框与"保存答案"仍可用，点击后才收到 `exam_deadline_exceeded` toast
  （exams.rs:64-71）；后端无任何到期事件，横幅可能直到下一次无关事件才出现——与
  "绝对截止时间"承诺不符。

## P3

### 28#4 Reports 页刷新无竞态守卫，慢的旧周期响应可覆盖新周期数据

- 位置：`desktop/src/pages/Reports.tsx:30-46`
- 证据：`refresh` 直接 `setReport(next)`，无 active/序号检查；周期切换或七类事件前缀触发
  的并发请求先发后至时旧响应最后落地，tab 与图表短暂错配（下一事件自愈）。

### 28#5 四个组件的事件监听器在卸载早于 promise resolve 时永不注销

- 位置：`desktop/src/components/UsagePanel.tsx:33-38`、`ExamWorkspace.tsx:76-80`、`SubjectivePractice.tsx:72-77`、`SyncPanel.tsx:33-39`
- 证据：均为 `.then(stop => { unlisten = stop })` 无 disposed 分支——与 24#6（useBackendState）
  同型泄漏的另外 4 处独立实例；对照正确写法 StudyRoom.tsx:132、AgentTaskCenter.tsx:47。
  StrictMode 每次挂载必漏一个；UsagePanel 泄漏后每次请求完成都空转刷新。

### 28#6 StudyRoom 的 target 消费标记永不复位，同挂载内重复跳转同一阶段被静默忽略

- 位置：`desktop/src/pages/StudyRoom.tsx:37,90-100`
- 证据：`consumedTarget.current` 只增不减；⌘K 搜索再点同一结果无任何反应。对照
  practiceTarget 专门带 `nonce: Date.now()`（App.tsx:264）规避此问题。

### 28#7 MediaPlayer 分块失败/哈希不匹配后无重试入口；全量载入内存无上限

- 位置：`desktop/src/components/MediaPlayer.tsx:17-44`
- 证据：任何一次 chunk 失败或 `hash !== info.sha256` 即终态错误，无重试按钮；`parts` +
  `Blob` + `blob.arrayBuffer()` 哈希三份瞬时副本——数 GB 视频预览内存峰值数倍于文件体积。

### 28#8 题目选项与引用的 React key 可碰撞

- 位置：`desktop/src/components/ExamWorkspace.tsx:150`（`key={option}` 选项文本重复即撞）、`:164` 与 `SubjectivePractice.tsx:134,136`（`materialId-quote` 同资料同句引用两次即撞）
- 证据：内容由模型生成无去重保证；对照 StudyRoom 的 citations key 用序号。

### 28#9 考试历史切换试卷时首题序号相同则上一份的选中项泄漏到新试卷

- 位置：`desktop/src/components/ExamWorkspace.tsx:47-52`
- 证据：切 setId 只 `setIndex(0)`，清空靠 `[index]` effect——两次 index 都是 0 时 effect
  不触发，`selected ?? …` 把旧卷选择高亮到新卷第一题，可能误提交。对照 SubjectivePractice
  在 setId effect 内显式清空（:38-44）。

### 28#10 SyncPanel 编辑弹窗被事件刷新整体覆盖未保存表单

- 位置：`desktop/src/components/SyncPanel.tsx:33-45`
- 证据：任何 `sync.` 事件触发 refresh → `setForm({...current, ...config})`，弹窗开着时
  一个上传完成即冲掉正在输入的 endpoint/remotePath。同型：SecurityPanel 的配额草稿
  （SecurityPanel.tsx:24-27）。

### 28#11 交卷（finalize）无确认对话框

- 位置：`desktop/src/components/ExamWorkspace.tsx:168`
- 证据：单击即不可逆定卷（未作答按 0 分计并写入证据）——20#5"破坏性操作缺确认"清单
  未覆盖的新实例。

### 28#12 复习页保持率等统计数字为字符串拼接（`stats.retention` 直渲染）——非缺陷，正面备注

- 位置：`desktop/src/pages/Review.tsx:120`
- 证据：`stats.retention === null` 处理正确（'—' 与无 % 后缀），列此条为 20 号清单外
  的正面样例；真正问题（文案相反）已在 19#4 记录，不重复。
