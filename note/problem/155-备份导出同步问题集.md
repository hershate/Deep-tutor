## P2

### 155#1 focus_sessions.task_id 悬挂——常规操作链（用过专注→删任务→导出）产出的备份在任何目标机整单拒导入

- 位置：`desktop/src-tauri/src/backend/backup/transfer.rs:688`
  （`task_id → kv:tasks` 父表校验）；豁免表 `:1280-1285`
  （`lenient_backup_parent` 仅 provider_requests/provider_route_runs/
  events）；失败面 `:1088-1094` + `:1370-1382`（非豁免码即
  `invalid_backup_reference`「任务与笔记集合 缺少记录 N」整单拒绝）。
- 缺口：任务删除（kv replace）时只 GC 笔记与项目（`store.rs:916-925`
  仅 notes→learning_annotations、projects→project_versions）；
  focus_sessions 建行时校验任务存在（reports/mod.rs:318-324）但删除后
  无 GC（全仓仅 clear_all 一处 DELETE，reports/mod.rs:212）。
- 传递链条：①对任务用过专注 → focus_sessions 行携带 task_id；②在任务
  列表删除该任务（常规操作，无任何阻止或级联）；③导出 .dtbackup——
  备份内 focus_sessions 引用了 kv:tasks 已不存在的 id；④任意目标机
  （含本人换机恢复）导入 → 父表校验失败 → **整份备份不可导入**，恢复
  路径完全阻断。与 99#6（provider_requests 悬挂，已修 lenient）同类
  同危害，但 kv 类父表未纳入豁免/置空口径。
- 影响范围：受影响=所有「用过专注后删除对应任务」的备份导出。损害
  性质=数据保全承诺失效（备份在需要时不可恢复），确定性触发。
- 修复方向：任务删除 GC focus_sessions（store.rs:916-925 补
  `DELETE FROM focus_sessions WHERE task_id NOT IN (…)`），或
  lenient_backup_parent 纳入 focus_sessions（导入侧置空）——建议双侧。

### 155#2 learning_plan_adoptions.project_id 悬挂——同族：采用方案进项目→删项目→备份不可导入

- 位置：`transfer.rs:686`（`project_id → kv:projects`）；项目删除时仅 GC
  project_versions（store.rs:919-925），adoptions 全仓无删除路径（仅
  learning/mod.rs:286 clear_all）。
- 传递链条：①采用方案 → learning_plan_adoptions 行携带 project_id；
  ②删除该项目；③导出/导入 → `invalid_backup_reference` 整单失败。
  同 155#1 机制，触发链更短（采用+删项目即成立，无需专注使用）。
- 影响范围：同 155#1。修复方向：项目删除 GC adoptions（或导入侧豁免
  置空 + detail() 读取时容缺）。

### 155#3 learning_plan_schedule_tasks / learning_node_tasks 的 task_id 悬挂（仅懒清理）

- 位置：`transfer.rs:688`；孤儿清理仅在打开对应方案周视图时惰性执行
  （`planning/mod.rs:145-191`，注释自述「kv 任务删除后，排期表没有按
  任务删除路径」）。
- 传递链条：删除任务后未再打开该方案即导出 → 备份携带悬挂行 → 导入
  整单失败。触发比 155#1/#2 多一步条件（懒清理未跑），危害同族。
- 修复方向：删除 GC 或导入侧豁免（三表一并收口）。

## 待核

### 155#5 OPML 导出未滤 C0 控制字符——可产出非法 XML 1.0

- `export/formats.rs:198-200`：`xml_attr` 仅 `\n→&#10;`、删 `\r`；
  `\x0B/\x0C/\x00-\x08` 等原样进入属性与 `<title>` 文本。上游无过滤
  （笔记/草稿校验只限长度/空白，material_text 解析亦不滤——PDF/Anki
  路径各自滤了：anki.rs:45-56、pdf.rs:328；OPML/CSV/TXT/MD 未滤，其中
  仅 OPML 因控制符整体解析失败）。触发：粘贴含垂直制表符的笔记 →
  OPML 导出 → 严格解析器拒收。export/tests.rs 无控制符用例。

### 155#6 原件导入扩展名不校验（加固项）

- `transfer.rs:1443-1456`：`materials/originals/{name}` 仅强校验
  stem==sha256（64hex 小写），扩展名任意/不限长（仅受 12 组件限制）。
  异常备份可落 `{64hex}.{任意}` 文件。有 DB 行级 sha 校验（137#1）与
  install 包含检查兜底，实际风险低。
