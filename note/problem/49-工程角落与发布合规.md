## P2

### 49#1 许可收集脚本命中 SPDX 元数据存根而非许可全文——MIT「附带许可声明」义务未履行

- 位置：`scripts/collect-licenses.mjs:31`（npm 侧 `find(file => /^licen[cs]e|notice/i.test(file))`）、`:93`（cargo 侧同型，`.crate` 回退路径同样先命中 `.spdx`）
- 证据（主审亲验）：`desktop/src-tauri/licenses/cargo-tauri-plugin-dialog-2.8.4-LICENSE.spdx` 已被收录，内容为 20 行 SPDX-2.1 元数据清单（DataLicense: CC0-1.0、PackageName: tauri…），**无任何许可全文**；registry 源码目录 `tauri-plugin-dialog-2.8.4/` 中 LICENSE_APACHE-2.0/LICENSE_MIT 全文实际存在但未被收录。机理：readdir 字母序中 `.`(0x2E) < `_`(0x5F)，`LICENSE.spdx` 恒排第一被 find 命中。同型：`cargo-tauri-plugin-fs-2.7.1-LICENSE.spdx`。
- **传递链条**：① `make build`/CI 运行 collect-licenses.mjs → ② 对 tauri-plugin-dialog/fs（及下次运行的 opener、tauri）取到 `.spdx` 存根 → ③ `bundle.resources: licenses/*` 把存根打进 NSIS 安装包 → ④ 分发的安装包对已随附的 MIT/Apache-2.0 直接依赖**不含许可全文**。
- **影响范围**：发布合规（MIT 第 1 条「在软件的所有副本中包含上述版权声明与许可声明」）；当前受影响为 dialog/fs 两个直接依赖，opener/tauri 在下次收集时同样命中。修复：优先级挑选（LICENSE/LICENSE.*（非 .spdx）/LICENSE-MIT/LICENSE_APACHE*/COPYING，`.spdx` 显式降级为最后回退）。
- **连带（P3 并列）**：当前 `desktop/src-tauri/licenses/` 生成于 opener 加入（1d1b326a，07:50）之前——**目录里 opener 许可文件为 0 个**（主审亲验 `grep -ci opener` = 0）；而 README.md:30-38 与 desktop/README.md:31-40 主推的 `npm run tauri build` 路径**不运行** collect-licenses，直接打包这份过期目录。按文档路径现在打出的安装包对 opener 一个许可文件都没有。修复：README 构建命令统一指向 `make build`，或把 collect-licenses 挂进 tauri beforeBuildCommand。
