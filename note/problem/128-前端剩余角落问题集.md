### 128#1 input/textarea/select 的 :disabled 零规则——作者样式覆盖 UA 灰化，禁用输入框与可编辑框视觉几乎一致

- 位置：`desktop/src/styles.css:91`（仅 `button:disabled`）+ `:97`（`input, textarea, select { color: var(--text); background: var(--surface-raised); }` 特异度覆盖 UA 的 GrayText 禁用灰化）。
- 传递链条：①真实存在的禁用输入：ExamWorkspace.tsx:205-206（已作答/过期考试的填空与简答框）、ProviderRouting.tsx:81-83（熔断参数保存中）、DataDirectoryPanel.tsx:101（busy 期目录输入）；②作者样式的 color/background 在禁用态继续生效；③禁用框与可编辑框视觉无差——用户反复点击/输入无反应且无任何视觉解释；④对照 `.export-grid > button:disabled`（:1318）说明项目有禁用态意识，漏了表单三件套。
- 影响范围：所有遇到禁用输入框的用户（考试已交/过期、参数保存中、目录变更中——看似可编辑实则不可）；按钮禁用态（有全局规则）不受影响；纯视觉误导，无功能损坏。
- 修复方向：补 `input:disabled, textarea:disabled, select:disabled { color: var(--muted); background: var(--surface-soft); cursor: not-allowed; }`。
