# 164 · 同步与导出边界

## 164#1 同步进度与完成路径可覆写取消状态

- 严重度：P2。
- 传递链：`sync::cancel` 将 running 改为 cancelling；工作线程在 `check_cancelled` 与下一次 `stage` 之间仍有窗口，`stage` 无条件把状态写回 running 并发 `sync.progress`；最终 `finish` 也无条件写 done/failed/cancelled，成功结果可覆盖此前保存的取消意图。
- 影响范围：WebDAV/S3 检测、上传、下载、导入与历史恢复；界面出现取消后又运行、取消后显示完成，调度器也可能把该次取消误作成功锚点。

## 164#2 运维页显示的结构版本不是实际 schema 版本

- 严重度：P3。
- 传递链：`maintenance::health` 只读取 `PRAGMA user_version`；项目约定该值只写 1，真实版本存于 `meta.schema_version` 且降级门取两者最大值。界面因此把 v4 数据显示为“结构版本 1”。
- 影响范围：本地数据检查、故障诊断与文档核对；不影响数据库迁移本身。

## 164#3 OPML 的换行保护与实际控制符过滤相互矛盾

- 严重度：P3。
- 传递链：`formats::xml_attr` 先调用 `xml_safe`，再试图把 `\n` 转为 `&#10;`；当前 `xml_safe` 只保留制表符并删除其他控制字符，换行在进入 `xml_attr` 前已被删除，注释承诺的多行结构无法保留。
- 影响范围：方案、讲义、笔记和资料的 OPML 导出与再解析；多行正文被拼接。

## 164#4 导出 HTML 未约束长无空格文本

- 严重度：P3。
- 传递链：`formats::html` 的内联样式没有 `overflow-wrap`；转义只能保证标记安全，不能阻止长 URL、哈希或无空格正文越过 `main`/`section` 限定宽度。
- 影响范围：导出的静态 HTML 在窄窗口中的阅读；不改变应用内 CSP 或脚本边界。
