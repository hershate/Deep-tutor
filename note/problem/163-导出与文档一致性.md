# 163 · 导出与文档一致性

## 163#1 讲义导出的事件刷新重新放入未采用方案

- 严重度：P2。
- 传递链：`ExportCenter` 初次加载在 lecture 范围过滤为已采用方案；plan.* 事件监听随后重新 `setPlans` 时只过滤 done/degraded，遗漏 adopted 条件。用户选择新进入的未采用方案后，`get_lecture` 被后端以 `plan_not_ready` 拒绝。
- 影响范围：讲义导出弹窗的方案选择、阶段读取与导出；实时刷新把初次加载已经排除的必败入口重新引入。

## 163#2 架构文档仍保留上一版关键数字

- 严重度：P3。
- 传递链：`docs/architecture/01-architecture.md` 的存储段仍写 SCHEMA_VERSION=3，运行原理与代码已为 4；`docs/architecture/03-workflow.md` 仍写当前 1.1.10，版本文件已为 1.1.11。读者按文档排查迁移或版本一致性会得到错误基线。
- 影响范围：架构理解、迁移审查、发布核对；不影响运行时代码。
