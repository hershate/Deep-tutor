# 61 · 前后端 IPC 契约机械比对（第二十四轮）

> 审计范围：前端 190 个唯一 invoke 命令（含 2 个 plugin:dialog）↔ main.rs
> 注册表 192 个 ↔ 各 commands.rs 签名逐参数比对；事件 123+ kind 三向比对；
> 重点域 serde 类型抽查（tauri 2.12.5 / @tauri-apps/api 2.12.4 锁定版本下
> 核实二进制通道返回形态）。
>
> **总体结论：命令层零断裂**——188 个后端命令的参数名（Tauri 2 默认
> camelCase 映射，无 rename_all 覆盖）、类型、可空性无一处错配；无 P2 级
> 发现。以下为 P3 与信息级。

## P3

### 61#1（=C-3）插件订阅白名单含 `app` 命名空间，后端无任何 `app.*` 事件——空指

- 位置：`desktop/src-tauri/src/backend/plugins/mod.rs:304`（白名单 `"app"`）；后端全部 emit kind 无 `app.` 前缀（最接近的是 `application.reset`，前缀不同且 `application` 也不在白名单）。
- 链条：插件清单声明 `app.*` 订阅 → 永远匹配不到事件（静默零投递，不报错）。
- 影响：白名单与真实事件面漂移；用户装了订阅 app.* 的插件得不到任何投递也无提示。修复：删除该命名空间或补齐对应事件。

### 61#2（=C-2）ExamWorkspace 不消费 examRemainingSeconds——倒计时纯前端时钟推导

- 位置：`desktop/src/backend/practice.ts:104`（类型已有）↔ `components/ExamWorkspace.tsx:68-80`（只用 examExpired/examDeadline 本地 Date.now() 差值）。
- 链条：后端每次 get_practice_set 返回权威 `examRemainingSeconds`，前端弃用；系统时钟回拨/跨设备时本地推导与后端判定（exam_deadline_exceeded）可能短暂不一致（提交时后端仍兜底拒绝）。契约一致、消费缺失，风险对称有限。
