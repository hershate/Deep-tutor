# 61 · 前后端 IPC 契约机械比对（第二十四轮）

> 审计范围：前端 190 个唯一 invoke 命令（含 2 个 plugin:dialog）↔ main.rs
> 注册表 192 个 ↔ 各 commands.rs 签名逐参数比对；事件 123+ kind 三向比对；
> 重点域 serde 类型抽查（tauri 2.12.5 / @tauri-apps/api 2.12.4 锁定版本下
> 核实二进制通道返回形态）。
>
> **总体结论：命令层零断裂**——188 个后端命令的参数名（Tauri 2 默认
> camelCase 映射，无 rename_all 覆盖）、类型、可空性无一处错配；无 P2 级
> 发现。以下为 P3 与信息级。

## P3

### 61#1（=C-3）插件订阅白名单含 `app` 命名空间，后端无任何 `app.*` 事件——空指

- 位置：`desktop/src-tauri/src/backend/plugins/mod.rs:304`（白名单 `"app"`）；后端全部 emit kind 无 `app.` 前缀（最接近的是 `application.reset`，前缀不同且 `application` 也不在白名单）。
- 链条：插件清单声明 `app.*` 订阅 → 永远匹配不到事件（静默零投递，不报错）。
- 影响：白名单与真实事件面漂移；用户装了订阅 app.* 的插件得不到任何投递也无提示。修复：删除该命名空间或补齐对应事件。

### 61#2（=C-2）ExamWorkspace 不消费 examRemainingSeconds——倒计时纯前端时钟推导

- 位置：`desktop/src/backend/practice.ts:104`（类型已有）↔ `components/ExamWorkspace.tsx:68-80`（只用 examExpired/examDeadline 本地 Date.now() 差值）。
- 链条：后端每次 get_practice_set 返回权威 `examRemainingSeconds`，前端弃用；系统时钟回拨/跨设备时本地推导与后端判定（exam_deadline_exceeded）可能短暂不一致（提交时后端仍兜底拒绝）。契约一致、消费缺失，风险对称有限。

## 信息性

### 61#3（=C-1）add_knowledge_task 返回自由 JSON、前端类型 unknown

- 链条：① 后端返回自由 Value（无 schema 约束）→ ② 前端以 unknown 接收、当前无消费方（32#19 注记）→ ③ 未来消费时需运行时校验或 typed struct。影响：无当前用户影响；属契约面的「类型不设防」残留点（45#2 家族）。

### 61#4（=C-4）events_since 前端未接线

- 链条：① 断线/重连后前端需要追平事件 → ② 直接走 get_app_state 全量快照校准（38#2 移除翻页）→ ③ events_since 命令仅剩 Rust 集成测试消费。影响：功能无缺口（全量拉取语义等价），代价是重连瞬间的全量 IPC；命令保留扩大 IPC 面，属设计取舍记录。

### 61#5（=C-5）focus.* 四事件无定向前端处理

- 链条：① 后端发 focus.started/interrupted/paused/resumed → ② 前端无精确匹配监听，仅全局 requestSyncCoalesced 消费 → ③ 触发 120ms 合并的全量状态拉取。影响：功能正确；最坏感知延迟一个刷新周期（如 interrupted 后专注层状态稍滞后）——信息级。

### 61#6（=C-6）regenerate scope 类型宽度差

- 链条：① 前端签名 scope:number → ② Rust 端 u8 反序列化 → ③ >255 时收到类型化 IPC 错误（非静默 undefined）。影响：当前调用方只传 0/1/2，永不可达；记录为契约宽度差异。

## 死命令（注册但前端零调用，4 个）

链条共性：① 旧路径命令被原生落盘版/内部复用取代 → ② 注册表未同步收缩 → ③ IPC 面与命令计数（192）包含四个零调用项。影响：无运行时开销（guard 直通未调用命令），属清理债——删除可对齐「已删 stream_provider_chat_with_tools」的先例（main.rs:258 注释）。

| 命令 | 位置 | 考证 |
|---|---|---|
| `export_usage_csv` | providers/commands.rs:245 | 37#5 注释明确被 `export_usage_csv_file` 替代，真死命令 |
| `export_practice_mistakes` | practice/commands.rs:78 | 同上，被 `_file` 版替代，真死命令 |
| `fetch_webpage` | web/commands.rs:9 | 仅 `import_webpage` 内部复用同一抓取链；IPC 面冗余 |
| `events_since` | commands.rs:112 | 仅 Rust 集成测试消费（见 61#4） |

（先例：`stream_provider_chat_with_tools` 曾因零调用被移除，main.rs:258 注释。）

## 死事件（后端发出、前端无定向处理，14 个 kind）

链条共性：① 命令层已同步返回结果（导出/保存/已读回执直接给前端）→ ② 后端仍按「终态先落盘再发送」同时发事件 → ③ 前端无精确监听，仅全局全量刷新消费。影响：不丢数据、不报错；代价是事件面冗余（计数虚高）与潜在的无谓全量刷新，列示供收敛参考。反向（前端监听后端从不发）为 **0**。

`application.reset`、`backup.exported`、`backup.imported`、`content.exported`、
`draft.saved`、`draft.deleted`、`focus.started`、`focus.interrupted`、
`focus.paused`、`focus.resumed`、`notifications.read`、`notifications.read_all`、
`report.exported`、`study.checkin_saved`。

## 已比对一致的重点接口（正向证据）

- saveMaterialFile（42#1/2）：签名、清洗、filters 全对齐。
- backup warnings：BackupResult{missingFiles,driftedFiles} camelCase 一致，旧 v3 档案 serde default 空表兼容。
- sync versions/配置：未配置返回 sync_not_configured；SyncVersion/SyncJobView/SyncConfigInput(deny_unknown_fields) 全对齐。
- exam timer：exam_expired/exam_remaining_seconds ↔ examExpired/examRemainingSeconds 一致。
- reports stop/FocusSession 8 字段、CheckinInput 等全对齐。
- 媒体二进制通道（46#2）：tauri 2.12.5 ipc-protocol 对非 JSON content-type 执行 arrayBuffer() ——前端 `invoke<ArrayBuffer>` 声明正确。
- 嵌套 Input serde 全检：IterationNoteInput/SubmissionInput/GoalInput/CardInput/PostInput 等全部 camelCase（多含 deny_unknown_fields）。
- 事件通道结构：backend://event 单通道，BackendEvent 四字段（createdAt serde rename）一致；插件白名单两端一致（除 61#1 空指）。
- guard_handler 仅就绪/登录前置门，不改命令契约。
