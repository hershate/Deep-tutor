## P3

### 87#1 亮色主题全局焦点圈对比度 1.05–1.31:1，键盘焦点近乎不可见

- 位置：`desktop/src/styles.css:31`（`--accent-bright: var(--lime-400)`）与 `:83`（`button/a/input/...:focus-visible { outline: 3px solid var(--accent-bright) }`）。
- 传递链条：①亮色主题下焦点圈用 lime-400（高亮度黄绿）；②与 paper-50 底比 1.25:1、纯白 1.31:1、accent-soft 底 1.05:1、surface-soft 1.13:1——全部远低于 WCAG 2.2 焦点外观 3:1 要求；③键盘用户 Tab 导航时无法定位焦点位置。暗色主题 13.79:1 正常。
- 影响范围：覆盖面最大的一条——亮色下**所有**可交互元素的键盘焦点圈失效。74 批修了「焦点圈禁」（焦点不逃逸），但圈本身颜色在亮色下不可见。
- 修复方向：亮色 outline 改 `var(--accent)`（实测 6.5:1）或 `--accent-strong`；或保留 lime 但外圈加深色 second outline。

### 87#2 `.hint-box` 练习提示文字 2.11:1

- 影响范围：亮色主题的练习提示两处；暗色覆盖（:598 换深底）7.68:1 通过，仅亮色失效。
