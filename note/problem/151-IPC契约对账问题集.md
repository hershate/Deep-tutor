## 信息

### 151#1 SyncJob.result 声明了 Rust 从不写入的两个键

- 位置：`desktop/src/backend/sync.ts:23`——TS 声明
  `result: null | { profiles?; routingMode?; activeProvider?; sha256?; … }`；
  Rust sync 域实际只写 `profiles/reachable/remoteConfirmed/sha256/bytes/
  historyPath/versions` 七键（sync/*.rs 全量核对），`routingMode`/
  `activeProvider` 在整个 Rust 树仅出现于备份表名映射与 providers 导出
  （与 sync 无关）。
- 传递链条：①两键为可选且 `SyncPanel.tsx` 只读 `result?.sha256`，
  无运行时影响；②类型声明超前/漂移，后续按 TS 类型消费这两键会拿到
  undefined。损害性质=死类型字段（142#1 ChatMessage 同类）。
- 影响范围：受影响=未来按该 TS 类型编码的同步面板演进（误信两键有值）；
  不受影响=当前运行时与同步任务本身。损害性质=声明漂移（无缺陷）。
- 修复方向：删除两键或补后端写入。
