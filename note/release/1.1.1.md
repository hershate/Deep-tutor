## 可靠性与正确性（后端）

- 单实例防护：命名互斥体 + 窗口前置的纯 Win32 FFI，双开时新进程把既有窗口带到前台后退出。
- SSE 流式解析改游标偏移行切分：消除 O(N²) 缓冲 drain，正确处理 CRLF/裸 CR/BOM；干净 FIN 或 EOF 零事件均归 endpoint_unreachable；工具调用索引上限 256，同 index 异 id 一律 fail-closed（OpenAI/Anthropic/Responses/Gemini 四协议一致）。
- 备份保真：清单缺失文件显式枚举（backupImportWarnings），导入侧缺件校验；tool_calls_json 内嵌 id 重写、缺列行剔除；三个备份命令异步化并传播会话身份。
- 媒体二进制通道：分块读取与校验命令走 tauri::ipc::Response，预览不再经 JSON number[] 数组往返；streaming_sha256 边读边算。
- 复习调度边界：间隔封顶 36500 天，ease/间隔有限性校验，next_day 越界错误化。
- 报表聚合：AVG 排除脏行、百分比钳制 0–100，focus_sessions(status,ended_at) 索引；专注收尾 planned 分钟封顶；停止操作逐域独立停并汇总。
- 计划数学：强度缩放去累积钳制、周小时浮点运算，孤儿任务删除收进 IMMEDIATE 事务。
- 同步调度：失败后 1 小时短退避（成功/取消恢复 24 小时）；取消状态条件修复。
- 时间与数值：now_local 缓存 UTC 偏移修复 Unix 多线程恒失败；考试计时从首次拉卷原子起算、重启不重置；免打扰与已存值相同即拒绝。
- 安全边界：API Key 1200 字节上限，keyring TooLong 映射类型化错误；异步阻塞命令显式传播会话 principal。
