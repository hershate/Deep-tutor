# 1.1.16

本版本清理废弃命令、生产构建中的测试专用代码和过时注释，不新增产品功能。

## 代码清理

- 删除 `stream_provider_chat` 命令包装，测试统一使用 `route_provider_chat` 验证真实路由、流式输出、重放和凭据清理。
- 删除 `get_agent_run` 命令包装，测试通过 `get_agent_session` 读取持久化运行记录。
- `events_since`、`EventPage`、直连测试辅助函数及存储辅助函数改为仅随 `cfg(test)` 编译，不再进入生产二进制。
- 删除冗余 `dead_code` 属性及已移除 IPC 壳的历史注释；生产 `cargo check` 无警告。
- `taskStatusNames` 与 `taskRoutes` 仅在定义文件内使用，取消导出。
- 保留路由兼容键、数据库迁移和历史 Skill：这些内容分别用于旧配置读取、存量数据升级和开发者资产展示，不属于未使用代码。
