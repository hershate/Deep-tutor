# 1.1.0

问题清单修复版本：note/problem 14 个文件 261 项全部处理完毕（修复、批判定落定或归类独立验收）；随后第七至十轮审计发现的 85 项（回归/残留/新发现）已在发布前修复完毕。

## 口径与行为变化

- 提示（hints）模式不再公布总分与正确率，完成页只显示完成题数；hints 作答不进错题本与正确率聚合。
- "有效学习"不双计：同一任务的专注计时与勾选计划分钟取较大者；任务未勾选时其关联专注秒按真实计时计入；首页可从任务行发起任务级专注。
- "本学期"改为秋季 9/1–次年 2 月末、春季 3/1–8 月末。
- 考试未作答不再写入错题本，仍按 0 分记录答案与掌握度证据。
- 变式答对沿链更新原错题掌握状态。
- 社区房间新建与预约拒绝时段重叠（room_time_conflict）。
- 社区 threads 配额计入回复（帖子与回复共用上限）；agent 记忆条数纳入配额（500 条）。
- 学习日历来源标签与数值实际来源一致（计时更长时标"计时"）。

## 功能与体验

- 插件安装事务化（存在性检查、落库、清单写入同事务，IMMEDIATE），失败只清理本次写入。
- 插件事件列表游标分页，集成页可加载更早历史。
- 孤儿扫描覆盖无清单目录与安装残留 tmp（24h 宽限），清理批量上限 500 项（失败项不占配额，报告剩余项）。
- 专注层与全局搜索独立组件化，计时与击键不再整页重渲染。
- ProviderHub 流式输出 150ms 合并拉取；取消竞态与首拉 not_found 静默；读路径 database_busy 不弹错，写路径失败必提示。
- PDF 缺字形以 □ 替代且占比 >1% 时随导出回执告警；导出文件名按码点截断。
- 供应商协议：流式重试退避、工具名消毒、OpenRouter reasoning 增量、max_tokens 上限 16384（上游拒绝超限时自动降级重试）；OpenAI Chat 历史消息按 wire 格式（snake_case）上线。
- 导出：PDF 缺字形降级、Anki 调度迁移（due 为自 crt 起的天数差）与稳定 guid（无 id 卡锚定正反面内容）。
- 笔记导入剥 BOM、归一 CRLF；frontmatter 命中元数据键才剥离；导出元数据换行折叠（往返一致）。
- 通知口径、日历合并（打卡与专注取大）、考试惰性收卷与同步健壮性修复。
- 深色模式补齐、大字号模式、可达性（焦点圈禁不抢 autoFocus、进度条语义）与死样式清理。
- 全局错误提示多槽堆叠；顶层错误边界（渲染异常不再整窗白屏）。

## 安全与合规

- WebView 启用 CSP（default-src 'self'；connect-src 含 ipc: 与本机回环），生产与开发分别配置；开发模式 devCsp 下若 Fast Refresh 失效请重启 dev 进程。
- 导出/备份/资料目的地拒绝落在应用数据目录内（防覆盖工作区数据库与原件）。
- API Key 的规范化副本与原始入参用后即擦（zeroize）；PAT 持有 Zeroizing；JWT 签名常数时间比较。
- 第三方许可文本随安装包分发（构建时收集 npm 与 Rust 依赖许可，CI 与本地构建一致强制）。
- 离线分享包与备份的 SHA-256 校验用于发现意外损坏，不证明发送者身份（离线信任模型限制）。
- Agent 工具的网络访问（web.fetch 等）在本地单用户模型下无需逐次审批，边界见《产品与技术决策》。
- 版本一致性检查（package.json/tauri.conf/Cargo.toml/README）进入 CI 与本地 lint。
