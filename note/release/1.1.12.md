# 1.1.12

修复 157–165 号问题，覆盖可选资料、通用问答、初次接入、状态恢复与动态内容边界。

## 学习闭环

- 方案资料改为 0–8 份可选项。无资料时可生成、采用方案并继续讲义、练习、考试、项目和导出；图谱、讲义、练习与评分不生成伪造引用。
- 有资料时继续校验引用范围与原文；填空题输入统一为 30000 字节上限。

## 通用问答与模型接入

- 全局导师与 Agent 支持不绑定方案的会话；通用 Agent 仅开放网络、记忆和历史工具，方案及产物工具要求绑定已采用方案，执行层保留拒绝守卫。
- 首个启用的供应商档案自动成为默认项，后续新增不覆盖已有选择；仅有显式任务路由时也可发送对应请求。
- 个人档案读取同步编辑草稿；每周投入统一为 1–80 小时；模型配置预览覆盖全部导出字段并隐藏无执行链的路由项。

## 状态与数据

- 方案、讲义、练习、项目、报告、资料、供应商、路由和同步恢复只处理仍处于活跃状态的主行，未翻行时不更新子行或发送终态事件。
- 同步进度不再复活取消中的任务，取消后保留已取得的结果；导出中心按方案采用状态过滤讲义。
- 备份原件扩展名与资料导入共用白名单，修复媒体与图片恢复后的断链；OPML 保留换行，HTML 长文本在容器内折行。

## 界面

- 动态文本与按钮在内容盒内折行，flex/grid 文本列允许收缩；代码、公式与表格仅在各自容器内滚动。
- 修复笔记公式定界、默认标签、社区侧栏忙碌状态、通知计数与维护页 schema 版本显示。

## 验证

- 回环协议覆盖无资料方案→采用→讲义、无资料练习→作答、无方案通用 Agent 问答，以及恢复、同步取消与图片备份恢复。
- `make check` 通过：252 个后端测试、六处版本一致、前端构建、npm audit 双口径与开发服务器冒烟。
- `make build` 生成 `dist/DeepTutor_1.1.12_x64-setup.exe` 及 SHA-256 文件；构建产物 `--verify-native` 完成真实 SQLite 初始化并退出，未打开窗口。
- 真实供应商、真实媒体编解码播放与交互安装仍为独立验收项。
