# Tauri 原生后端功能覆盖清单

> 建档：2026-11-02。目标：REF 界面中的所有交互都由原生后端提供真实结果，
> 不以 `setTimeout`、本地假数据或界面提示冒充后端能力。

## 一、目标架构

- **进程内后端**：`desktop/src-tauri/src/backend/`。Tauri commands 提供请求/响应，
  Tauri events 提供实时输出，不恢复独立 Web 服务。
- **持久化**：应用数据目录中的 SQLite。结构化状态、任务执行记录和事件 outbox
  均持久化；大文件与材料原件放应用数据目录的文件区。
- **实时协议**：后端事件带单调递增 id，前端按 Last-Event-ID 续接；
  终态先落盘再发送，断线不重复执行、不重复计费。
- **密钥**：API Key 经一次性表单进入系统密钥库；数据库、WebView 持久化、
  日志、导出和同步载荷均不保存明文。
- **外部能力**：模型协议、网页抓取、WebDAV/S3 由后端实际执行；
  未配置或不可用时返回明确错误，不生成模拟成功结果。
- **冗余清理**：Python/Reasonix 旧后端只在新实现覆盖对应语义后删除，
  不以“清理”为名留下无实现功能。

## 三、实施顺序

1. 状态/事件基础设施，任务/笔记/资料/项目/偏好与备份。
2. 生成流水线、材料、学习空间、练习、复习和报告。
3. Agent、模型中心、实时任务、路由和同步。
4. 社区、安全、插件、分享、导出与旧后端清理。

每片都要求：命令单测覆盖真实读写；前端调用真实命令；实时事件可续接；
安装包内运行验证；对应模拟代码删除后才标记完成。

## 四、验收总线

- `cargo test`：后端逻辑、迁移、事件顺序、配额、导入导出和协议测试。
- `npm run build`：TypeScript 契约无断裂。
- 真实 Tauri：跨页写入恢复、任务实时输出、断线续接、安装/卸载。
- 外部依赖测试使用明确测试服务，不把模拟服务结果算作真实供应商验收。
- 最终扫描不得保留 `setTimeout` 模拟、假“连接成功”或未经后端产生的“已完成”。
