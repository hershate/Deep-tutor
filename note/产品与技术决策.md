# 当前产品与技术决策

> 本文只记录当前有效决策。旧 Reasonix 服务路线、四前端、全登录服务和 shim
> 已废止；Python 插件仅保留待原生覆盖的参考实现。历史通过 git 历史追溯。

## 一、交付形态

1. **唯一交付物**是 Tauri 2 + `REF/frontend/app` 的桌面安装包。
2. 不再交付浏览器 SPA、Electron、`frontend-next`、旧前端插件示例、
   剪藏扩展、网页启动脚本或服务器运行环境。
3. `scripts/start.ps1`、`scripts/start.sh` 与 `stage.md` 已删除。
   项目现状只通过 git commit description 记录。

## 二、原生后端

4. REF 中的全部功能必须接入 Tauri 原生后端，前后端逻辑一致并输出真实结果。
5. 后端位于 `desktop/src-tauri/src/backend/`，通过 Tauri commands 处理请求、
   通过 Tauri events 推送实时输出，不以独立 HTTP 服务作为连接方式。
6. SQLite 保存业务状态、执行记录和事件 outbox；大文件放应用数据目录文件区。
7. 实时事件使用单调递增 id，支持 Last-Event-ID 续接。
   终态先落盘再发送，断线不重复执行、不重复计费，取消/异常计量不丢失。
8. 未配置或不可用的外部能力必须返回明确错误，不得以模拟成功代替真实实现。

## 三、数据、密钥与安全

9. API Key 只能经一次性表单进入系统密钥库；不得进入 WebView 长期存储、
   SQLite 明文列、日志、导出、同步载荷或测试夹具。
10. 材料、上传、URL 和导出在后端执行类型/大小/路径/网络安全检查；
    不接受伪造的“已验证”结果。
11. 备份导入采用预演与追加语义；分享只读、可撤销、可过期；
    导出内容不包含密钥和越权数据。全量 `.dtbackup` 包含一致性 SQLite 快照、
    原生领域表、材料原件、声明式插件与 Agent scratch 文件，逐项校验路径和哈希；
    冲突 ID 映射保留双方，已有偏好与路由不覆盖，系统凭据、PAT 摘要、JWT 会话和分享原始令牌不入包。
    本地用户具有管理员／成员角色；JWT 使用 HS256 与七日有效期，明文只存系统密钥库，
    PAT 使用系统随机数且只在创建时返回一次，数据库仅存 SHA-256 摘要；停用／移除用户撤销会话与 PAT，
    移除用户不连带删除学习记录。账户元数据保存在根库，学习数据、材料、插件、凭据与事件按用户分目录；
    首位用户旧工作区只复制一次，业务命令统一验证会话并继承到后台线程，切换前停止旧任务。
    配额读取当前用户工作区，笔记、材料、Agent 会话与社区讨论在提交前强制限额，拒绝写入不影响其他用户。
    分享只暴露哈希索引供只读令牌定位；快照携带工作区 ID 与事件代次，过期后可重新选择本地用户。
    报告只使用真实记录：专注保存实际秒数与暂停恢复，已完成任务保留计划分钟并明确区分；
    无证据不填示例趋势，日历保留计时与自报来源，采纳建议一次提交，CSV 由后端真实导出。
    搜索读取当前工作区的页面、笔记、材料、方案与知识节点；通知按真实到期事项生成并保存已读与免打扰状态。
    个人档案、导师风格与免打扰设置按用户持久化，诊断只新增开始时间；首页目标、复习、连续记录与建议均来自真实状态。
    计划页读取真实方案排期、待排任务与阶段阅读状态，任务可直接安排日期；强度按当前强度与目标强度的比例调整，避免往返切换累积缩放，替代方案使用实际分钟计算。目标修改进入原生再生成并呈现进度或错误；已采用方案不得原地重跑，须保留历史并创建新方案。
    Markdown/TXT/ZIP 笔记导入由 Rust 读取，限制 64 MB 文件与解压总量、1 MB 单条正文、1000 个条目和压缩比；拒绝危险路径、非 UTF-8 与空正文，校验后在单个事务中追加，不覆盖已有笔记。原生导出包恢复标题、标签和正文，提交快照直接回写前端并发送事件，不再使用浏览器 JSZip。
    资料库的知识关联只来自学习阶段批注映射的实际节点；删除笔记同步清理关联。知识库检查读取真实的未关联自由笔记、完全相同的正文、缺失原件与解析失败，支持打开对应记录，不自动删除内容，也不生成固定检查结论。
    Agent 的 web.search 使用无需密钥的 DuckDuckGo HTML 公开检索，只有实际抓取成功的候选才标记已验证；web.fetch 提取真实 HTML／纯文本，不执行脚本。网页地址禁止内嵌凭据与常见密钥参数，DNS 校验与连接固定同一组公网地址、禁用代理绕过，每次重定向重新校验且最多 3 次，仅接受 UTF-8 文本，响应限 1 MB、工具文字限 256 KiB；测试回环例外不进入生产构建。
    方案 URL 输入通过同一抓取通道保存提取正文、内容哈希和最终来源 URL，复用材料去重、解析、备份与用户配额。资源检索只列出实际验证网页，失败保留本地资料并记录真实错误；已验证网页可再次抓取导入，不以摘要替代正文。
    知识地图可将选中节点传入练习配置；练习可选 nodeId 并持久化，后端验证节点属于方案、所选阶段和变式范围，提示词及返回题目均受该范围约束，恢复任务不得扩大范围。未指定节点时保持既有阶段或整方案行为。
    项目成果保存独立版本、提交正文、里程碑与可选资料，量规由真实模型按概念应用、实现质量、验证与反思评分，不声称执行代码。反馈任务先落库再发事件，支持实时输出、取消、失败恢复、重启中断与结果重放；版本和反馈纳入备份，迭代想法写入真实笔记。项目统计只来自里程碑与实际完成评价，关联概念打开对应方案知识地图。
    MP4、MOV、M4V、WebM、MP3、WAV、OGG、M4A 与常见图片可经原生签名检查导入并预览；原件按数据库哈希定位并验证路径，读取前校验 SHA-256，按 256 KiB 分块进入应用内播放器。媒体仅作原件预览，不生成字幕、OCR 或内容识别，也不进入文字模型的方案资料；不自动播放。
    WebDAV/S3 同步只包含脱敏供应商档案与任务路由，不上传学习备份或远端密钥；
    上传须经远端回读校验，任务终态先落盘再通知。自动同步按 24 小时到期调度，
    每次上传保留独立历史对象，远端只保留最近 10 个，恢复必须选择真实历史对象。
    运维检查读取真实 SQLite 完整性、外键、页面与 WAL 状态；仅清理应用数据目录中
    无数据库引用的白名单文件与可识别临时项，缺失原件只报告不替代，异常数据库不清理。
    清理和整理前停止活动任务，结束后恢复自动同步调度；高于当前结构版本的数据库拒绝降级修改。

## 四、实现与清理

12. 以 `note/14-Tauri原生后端覆盖清单.md` 为功能与验收基准。
    每个功能切片完成后，必须删除对应模拟分支，而不是并存两套结果。
13. Python/Reasonix 旧后端只在新实现覆盖后按冗余清理；
    不得先删除再留下无实现功能，也不得保留无人使用的产品路径。
14. 文档只保留当前有效内容。历史通过 git 历史追溯，不新建进度日志或重复档案。
15. 验证必须覆盖真实命令、持久化、事件续接和安装包内运行；
    仅编译、仅界面展示或仅模拟服务均不能视为完成。

## 五、工程纪律

16. 改造分支为 `refactor/reasonix`；细粒度中文 commit，禁止 co-author，不 push。
17. 先复用现有工具与缓存，不随意安装环境。Rust 可复用
    `F:\DevCache\toolchains\1.95-x86_64-pc-windows-msvc`。
18. 上游 Reasonix 代码与文档的引用和修改披露保留在 `NOTICE` 与
    `LICENSE-REASONIX`；展示品牌变化不得改写机器识别的协议名、许可名或历史事实。
