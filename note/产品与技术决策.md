# 当前产品与技术决策

> 本文只记录当前有效决策。旧 Reasonix 服务路线、四前端、全登录服务和 shim
> 已废止；Python/Reasonix 旧实现已删除，历史通过 git 历史追溯。

## 一、交付形态

1. **唯一交付物**是 Tauri 2 + `REF/frontend/app` 的桌面安装包。
2. 不再交付浏览器 SPA、Electron、`frontend-next`、旧前端插件示例、
   剪藏扩展、网页启动脚本或服务器运行环境。
3. `scripts/start.ps1`、`scripts/start.sh` 与 `stage.md` 已删除。
   项目现状只通过 git commit description 记录。最终 NSIS 安装包统一输出到根目录
   `dist/`，构建成功后复制并校验 SHA-256。安装目录、开始菜单目录及安装包名称使用
   ASCII 的 `DeepTutor`；界面品牌保留“知舟”，`com.deeptutor.workspace` 标识及既有
   学习数据位置不变，不限制用户主动选择的目录字符。

## 二、原生后端

4. REF 中的全部功能必须接入 Tauri 原生后端，前后端逻辑一致并输出真实结果。
5. 后端位于 `desktop/src-tauri/src/backend/`，通过 Tauri commands 处理请求、
   通过 Tauri events 推送实时输出，不以独立 HTTP 服务作为连接方式。
6. SQLite 保存业务状态、执行记录和事件 outbox；大文件放应用数据目录文件区。
7. 实时事件使用单调递增 id，支持 Last-Event-ID 续接。终态先落盘再发送，
   断线不重复执行、不重复计费，取消/异常计量不丢失。
8. 未配置或不可用的外部能力必须返回明确错误，不得以模拟成功代替真实实现。

## 三、数据与密钥边界

9. API Key 只能经一次性表单进入系统密钥库；不得进入 WebView 长期存储、
   SQLite 明文列、日志、导出、同步载荷或测试夹具。
10. 材料、上传、URL 和导出在后端执行类型/大小/路径/网络安全检查；
    不接受伪造的“已验证”结果。

## 四、已实现能力语义

### 备份与分享

- 备份导入采用预演与追加语义；分享只读、可撤销、可过期（例外：离线导出包脱离本机数据库，无法接收撤销，校验值仅检测损坏、不证明来源，界面上须明示）；
  导出内容不包含密钥和越权数据。
- 全量 `.dtbackup` 包含一致性 SQLite 快照、原生领域表、材料原件、声明式插件与
  Agent scratch 文件，逐项校验路径和哈希。冲突 ID 映射保留双方，已有偏好与路由
  不覆盖；系统凭据、PAT 摘要、JWT 会话和分享原始令牌不入包。
- 分享只暴露哈希索引供只读令牌定位；定位索引（share_index）携带用户标识、
  应用状态快照（app_state）携带工作区 ID，分享包本体（SharedPlanSnapshot）
  不含两者（13#21/22 复核：
  事件代次与“过期后重选本地用户”原先仅是声明、无对应实现，已从决策中
  移除；如需增量备份或分享过期迁移，须先补充设计与实现再写回）。

### 用户、凭据与工作区隔离

- 本地用户具有管理员／成员角色。JWT 使用 HS256 与七日有效期，明文只存系统密钥库；
  PAT 使用系统随机数且只在创建时返回一次，数据库仅存 SHA-256 摘要。
- 停用／移除用户撤销会话与 PAT；移除用户不连带删除学习记录。
- 同一时刻仅保留一个活动会话：登录签发即撤销全部仍活跃的旧会话并清理其
  凭据槽，登出撤销该用户全部会话；PAT 登录（authenticate_access_token）
  验证后经同一签发路径建立会话。
- 账户元数据保存在根库，学习数据、材料、插件、凭据与事件按用户分目录。
  首位用户旧工作区只复制一次；业务命令统一验证会话并继承到后台线程，
  切换前停止旧任务。tauri 异步命令体运行在 tokio worker，不继承
  thread-local 身份——由会话派生当前用户（session_principal，与守卫
  同源）再传播进阻塞线程；无身份打开数据层返回类型化错误，不回退
  默认用户。

### 配额

- 配额读取当前用户工作区。笔记、材料、Agent 会话与社区讨论在提交前强制限额；
  拒绝写入不影响其他用户。

### 学习报告

- 报告只使用真实记录：专注保存实际秒数与暂停恢复，已完成任务保留计划分钟并明确区分。
- 无证据不填示例趋势；日历保留计时与自报来源；采纳建议一次提交；
  CSV 由后端真实导出。

### 搜索与通知

- 搜索读取当前工作区的页面、笔记、材料、方案与知识节点。
- 通知按真实到期事项生成，并保存已读与免打扰状态。

### 个人化与首页

- 个人档案、导师风格与免打扰设置按用户持久化；诊断只新增开始时间。
- 首页目标、复习、连续记录与建议均来自真实状态。

### 计划与强度

- 计划页读取真实方案排期、待排任务与阶段阅读状态，任务可直接安排日期。
- 强度按当前强度与目标强度的比例调整，避免往返切换累积缩放；
  替代方案使用实际分钟计算。
- 目标修改进入原生再生成并呈现进度或错误；已采用方案不得原地重跑，
  须保留历史并创建新方案。

### 笔记导入导出

- Markdown/TXT/ZIP 笔记导入由 Rust 读取：限制 64 MB 文件与解压总量、1 MB 单条正文、
  1000 个条目和压缩比；拒绝危险路径、非 UTF-8 与空正文；校验后在单个事务中追加，
  不覆盖已有笔记。
- 原生导出包恢复标题、标签和正文；提交快照直接回写前端并发送事件，
  不使用浏览器 JSZip。

### 知识关联与资料库检查

- 资料库的知识关联只来自学习阶段批注映射的实际节点；删除笔记同步清理关联。
- 知识库检查读取真实的未关联自由笔记、完全相同的正文、缺失原件与解析失败，
  支持打开对应记录；不自动删除内容，也不生成固定检查结论。

### Agent 网页检索与抓取

- `web.search` 使用无需密钥的 DuckDuckGo HTML 公开检索；
  只有实际抓取成功的候选才标记已验证。
- `web.fetch` 提取真实 HTML／纯文本，不执行脚本。
- 网页地址禁止内嵌凭据与常见密钥参数；DNS 校验与连接固定同一组公网地址、
  禁用代理绕过；每次重定向重新校验且最多 3 次；仅接受 UTF-8 文本；
  响应限 1 MB、工具文字限 256 KiB。
- 测试回环例外不进入生产构建。
- Agent 的网络检索与抓取在本机单用户模型下不设逐次审批弹窗：工具调用
  直接执行并完整记录于 agent_tool_calls 表（含 URL 与结果摘要），供
  事后审计；如需更强边界可通过停用对应插件或断网实现。

### 方案 URL 与资源检索

- 方案 URL 输入通过同一抓取通道保存提取正文、内容哈希和最终来源 URL，
  复用材料去重、解析、备份与用户配额。
- 资源检索只列出实际验证网页；失败保留本地资料并记录真实错误；
  已验证网页可再次抓取导入，不以摘要替代正文。

### 知识节点针对练习

- 知识地图可将选中节点传入练习配置；练习可选 nodeId 并持久化。
- 后端验证节点属于方案、所选阶段和变式范围；提示词及返回题目均受该范围约束，
  恢复任务不得扩大范围。未指定节点时保持既有阶段或整方案行为。

### 项目成果与量规反馈

- 项目成果保存独立版本、提交正文、里程碑与可选资料；量规由真实模型按概念应用、
  实现质量、验证与反思评分，不声称执行代码。
- 反馈任务先落库再发事件，支持实时输出、取消、失败恢复、重启中断与结果重放；
  版本和反馈纳入备份；迭代想法写入真实笔记。
- 项目统计只来自里程碑与实际完成评价；关联概念打开对应方案知识地图。

### 媒体原件预览

- MP4、MOV、M4V、WebM、MP3、WAV、OGG、M4A 与常见图片可经原生签名检查导入并预览。
- 原件按数据库哈希定位并验证路径；读取前校验 SHA-256，按 256 KiB 分块进入应用内播放器。
- 媒体仅作原件预览：不生成字幕、OCR 或内容识别，不进入文字模型的方案资料，
  不自动播放。

### ZIP 资料包

- 由 Rust 在内存中预检：限制 50 MB 压缩包、64 个文件、单项 50 MB、总解压 200 MB、
  200 倍压缩比；拒绝路径穿越、嵌套 ZIP、损坏或不支持加密内容。
- 所有支持条目通过检查后才复用原材料暂存、哈希去重和事件；未支持类型单独计数；
  不在文件系统解包。

### WebDAV/S3 同步

- 同步只包含脱敏供应商档案与任务路由，不上传学习备份或远端密钥。
- 上传须经远端回读校验；任务终态先落盘再通知。
- 自动同步按 24 小时到期调度；每次上传保留独立历史对象，远端只保留最近 10 个；
  恢复必须选择真实历史对象。

### 数据运维

- 运维检查读取真实 SQLite 完整性、外键、页面与 WAL 状态。
- 仅清理应用数据目录中无数据库引用的白名单文件与可识别临时项；
  缺失原件只报告不替代，异常数据库不清理。
- 清理和整理前停止活动任务，结束后恢复自动同步调度；
  高于当前结构版本的数据库拒绝降级修改。

### 统计与练习口径（03 批判定落定）

- 提示（hints）反馈模式不公布分数：逐题与整组（set 级）得分、正确率一律遮蔽，
  完成页只显示完成题数；数据库仍如实保存分数用于记录。
- “有效学习”不双计：同一任务的专注计时秒与勾选计划分钟只取较大者；
  未关联任务的专注按实际秒全额计入（任务未勾选时其关联专注秒仍按真实
  计时计入）。首页与周报使用此任务级口径；学习日历/热力图为独立的
  日级口径——每日取“自报打卡分钟与专注计时分钟”的较大值，任务勾选
  分钟不进日历、自报打卡不进周报，两者描述不同视图、并非同一公式。
- “本学期”窗口：秋季 9/1 起至次年 2 月末、春季 3/1 起至 8 月末，
  寒暑假月归入刚结束的学期。
- 考试未作答≠做错：未答题按 0 分计并保留答案与掌握度证据，但不写入错题本、
  不参与变式来源。
- 变式掌握沿链传播：对变式再生成变式并答对时，中间错题与原错题一并标记掌握。
- 社区房间同一时段只保留一个预约：新建房间与预约均拒绝与现有排期重叠的时段。
- 社区 threads 配额按帖子与回复总数计，回复创建同样受上限约束（03#10 用户判定：计入）。
- 主观题生成为“默认简答与论述各 1 道”，提示词要求多类别均衡分布，
  不承诺固定组成（以模型实际生成为准）。

## 七、启动与故障恢复

18. 默认应用数据目录和数据库在启动时自动创建，不再使用原生启动确认框或隐藏主窗口。
    目录类型、权限、数据库、密钥库或装配失败必须在主窗口显示实际错误代码，并提供
    原生重试、修改目录及恢复默认的入口；初始同步失败、会话失效及事件监听失败同样
    不得只留下无限加载界面。
19. 数据目录可在“设置 → 隐私、备份与数据”中修改。独立配置文件保存在应用本地配置目录，
    只接受明确的本机绝对目录；保存时验证目录与 SQLite，修改在下次启动时生效。切换不
    自动搬移、覆盖或删除旧目录数据，需要迁移时先导出备份再在新目录导入；目录配置不
    作为学习备份中的绝对路径恢复。初始后端等待超过 20 秒时可重试，重试不得清除学习数据。
20. `--verify-native` 是仅用于无界面验收的显式入口：只使用调用者指定的独立绝对目录，
    不弹出确认框、不创建窗口，也不访问日常数据目录或日常目录配置。
21. 数据库打开时以「完整 schema 指纹 + 代码侧 schema 版本（SCHEMA_VERSION，当前 2）」
    双条件判断是否需要迁移：指纹不同（外部漂移或首次打开）或记录版本低于代码版本
    都执行迁移——指纹只反映库内现状、不反映代码期望，漏递增版本号的存量库靠版本
    门禁补跑 DDL 补列；旧库只记指纹不记版本按 0 处理，强制补跑一次后写入版本。
    结构未变且版本一致时不重复执行全套 DDL，漂移仍须修复。本地账户库复用连接，
    数据库守卫在调用其他账户操作或命令前释放，避免为减少打开次数引入锁重入。
22. 材料解析最多使用一个工作线程，避免启动时同时读取所有原件。待解析任务保留在
    SQLite，等待中的任务可取消，停止后不自动启动下一项；恢复时继续队列，
    接续登记先于旧任务移除，不能提前显示空闲。

23. SQLite 连接统一 `PRAGMA synchronous=NORMAL`（WAL 常规搭配）。FULL 的每提交
    fsync 在 Windows 上放大流式 delta 的写延迟；NORMAL 下断电最多丢失最后一次
    已确认提交（WAL 不损坏、checkpoint 仍可靠），事件 outbox 的单调 id、终态先
    落盘再发送与 Last-Event-ID 续接语义不受影响——重启后由 outbox/请求记录重放
    对齐。迁移按第 21 条指纹 + schema 版本双条件判断，结构未变且版本一致时不
    重复执行全套 DDL；"schema 降级拒绝"（高于当前应用版本的库拒绝打开）由
    `PRAGMA user_version` 门禁实现并报 `unsupported_schema`，指纹核对只触发
    迁移不产生拒绝，其亚毫秒级固定成本视为设计取舍，不做进程级缓存。
